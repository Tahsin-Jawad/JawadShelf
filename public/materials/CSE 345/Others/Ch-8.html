পেইজ ১৭৭–১৮৯, সব পেইজ। গেট-ডায়াগ্রামে বইয়ের মতোই আঁকা: ● ডট = ওই উল্লম্ব লাইনটা গেটের ইনপুটে যুক্ত, ডট না থাকলে যুক্ত না। (এই বইয়ে MUX/DEMUX এই অংশে নেই, শুধু ইন্ট্রোতে ধারণা আছে।)

পেইজ ১৭৭ – 8.1 Introduction ও 8.2.1 Encoder শুরু

  • n বিটের binary code দিয়ে সর্বোচ্চ 2ⁿ টা আলাদা জিনিস বোঝানো যায়। Discrete ইনপুটকে binary code-এ বদলায় Encoder, উল্টোটা করে Decoder। এক code থেকে আরেক code-এ বদলানোর জন্য Code converter (বিশেষ ধরনের encoder)।
  • Multiplexing: অনেক তথ্য-ইউনিট কম সংখ্যক লাইনে পাঠানো (many → one)। Demultiplexing: উল্টো, কম লাইনে আসা তথ্য অনেক জায়গায় ছড়িয়ে দেওয়া (one → many)।
  • Encoder: ২ⁿ (বা কম) ইনপুট লাইন, n আউটপুট লাইন। একসময়ে একটাই ইনপুট active থাকে, আউটপুট সেই ইনপুটের binary code দেয়।
  • Active-LOW ইনপুট: active লাইন 0, বাকিগুলো 1। Active-HIGH ইনপুট: active লাইন 1, বাকিগুলো 0।
  • Octal-to-binary (8-to-3 line) encoder-এর সূত্র, active-LOW:
O₀ = D₁′+D₃′+D₅′+D₇′ = (D₁D₃D₅D₇)′O₁ = D₂′+D₃′+D₆′+D₇′ = (D₂D₃D₆D₇)′O₂ = D₄′+D₅′+D₆′+D₇′ = (D₄D₅D₆D₇)′
মুখস্থ ট্রিক: O₀ = যাদের binary-র শেষ বিট 1 (D₁,3,5,7)। O₁ = মাঝের বিট 1 (D₂,3,6,7)। O₂ = প্রথম বিট 1 (D₄,5,6,7)।

Priority Encoder

  • সাধারণ encoder IC আকারে পাওয়া যায় না (গেট দিয়ে সহজেই বানানো যায়)। IC-তে পাওয়া যায় priority encoder।
  • এতে প্রতিটা ইনপুটে priority থাকে। একসাথে একাধিক ইনপুট active হলে সর্বোচ্চ priority-র ইনপুট encode হয়। বড় subscript = বেশি priority ধরলে D₂ ও D₅ একসাথে active হলে আউটপুট 101 (D₅ জেতে)।

পেইজ ১৮০ – 8.3 Decoders: 3-to-8 (Binary-to-octal) সূত্র

  • Decoder: n-ইনপুট (binary code) নেয়, কোডের সাথে মেলানো শুধু একটা আউটপুট active করে। আউটপুট সর্বোচ্চ 2ⁿ টা।
  • Active-LOW আউটপুট: active আউটপুট 0, বাকি 1। Active-HIGH: active 1, বাকি 0।
  • অব্যবহৃত (invalid) কোড দিলে ২ⁿ-র কম আউটপুটওয়ালা ডিকোডারে সব আউটপুট inactive থাকে।
  • 3-to-8 line decoder = 1-of-8 decoder = binary-to-octal decoder।

Active-LOW আউটপুট (NAND বা OR আকারে):

O₀ = A₂+A₁+A₀ = (A₂′A₁′A₀′)′ ... O₇ = A₂′+A₁′+A₀′ = (A₂A₁A₀)′

Active-HIGH আউটপুট (শুধু AND, প্রতিটা একটা minterm):

O₀=A₂′A₁′A₀′ O₁=A₂′A₁′A₀ O₂=A₂′A₁A₀′ O₃=A₂′A₁A₀O₄=A₂A₁′A₀′ O₅=A₂A₁′A₀ O₆=A₂A₁A₀′ O₇=A₂A₁A₀
নিয়ম: Oₖ = binary(k)-র minterm। বিট 1 হলে সরাসরি, 0 হলে complement। Active-LOW = এই minterm-কে NAND করা।

Decoder with Enable

  • Enable ইনপুট সক্রিয় থাকলে ডিকোডার স্বাভাবিক কাজ করে। সক্রিয় না থাকলে কোনো আউটপুটই active হয় না।
  • উদাহরণ: 2-to-4 decoder, active-LOW আউটপুট, active-LOW enable (E = 0 হলে চালু):
O₀ = E+A₁+A₀ = (E′A₁′A₀′)′ O₁ = E+A₁+A₀′ = (E′A₁′A₀)′O₂ = E+A₁′+A₀ = (E′A₁A₀′)′ O₃ = E+A₁′+A₀′ = (E′A₁A₀)′
Enable মানে একটা বাড়তি ইনপুট যা প্রতিটা গেটে ঢোকে। E ঠিক থাকলে গেট খোলা, না হলে সব আউটপুট 1 (active-LOW-তে inactive)।

8.3.3 Decoder Expansion

  • বড় ডিকোডার দরকার হলে ছোট ডিকোডারকে enable ইনপুট দিয়ে জোড়া লাগানো যায়। Fig 8.10(a): 2×4 দিয়ে 3×8; (b): 2×4 দিয়ে 4×16।
  • 3×8: A₂ = 0 হলে D1 চালু, D2 বন্ধ → O₀–O₃ একটা জ্বলে। A₂ = 1 হলে D2 চালু, D1 বন্ধ → O₄–O₇ একটা জ্বলে। D1-এর E সরাসরি A₂, D2-এর E-তে A₂′ (NOT)।
  • উদাহরণ: A₂A₁A₀ = 101 → D2 enable (A₂=1), তার A₁A₀ = 01 মানে O₁ → মোট ডিকোডারের O₅ active।

পেইজ ১৮৬ – Fig 8.10: Expansion ডায়াগ্রাম

(a) 3×8 decoder = 2×4 দুটো (সংক্ষিপ্ত ব্লক ডায়াগ্রাম)

(b) 4×16 decoder = 2×4 পাঁচটা: D1 উপরের ২ বিট (A₃A₂) decode করে, তার ৪ আউটপুট D2–D5-এর enable চালায়

  • A₃A₂ = 00 → D1-এর O₀ = LOW → D2 চালু। 01 → D3, 10 → D4, 11 → D5।
  • উদাহরণ: A₃A₂A₁A₀ = 0110: A₃A₂ = 01 → D1-এর O₁ LOW → D3 চালু। A₁A₀ = 10 → D3-এর O₂ active → মোট ডিকোডারের O₆।

পেইজ ১৮৭ – 8.3.4 Decoder দিয়ে Combinational Logic (SOP)

  • Decoder ২ⁿ টা minterm (active-HIGH) বা maxterm (active-LOW) দেয়। যেকোনো Boolean function = minterm-এর যোগ বা maxterm-এর গুণ। তাই n ইনপুট, m আউটপুটের যেকোনো সার্কিট = n-to-2ⁿ decoder + m টা OR/NAND বা AND/NOR গেট।
  • Canonical SOP: function-এর ইনপুটগুলো decoder-এ দাও। Active-HIGH decoder হলে function-এর minterm-এর আউটপুটগুলো OR করো। Active-LOW decoder হলে সেগুলো NAND করো (DeMorgan)।
F₁(A,B,C) = Σ(1,2,4,7) F₂(A,B,C) = Σ(0,5,6,7)

Fig 8.11(a) – active-HIGH decoder (E = 1), OR গেট। O₁, O₂, O₄, O₇ → F₁। O₀, O₅, O₆, O₇ → F₂।

Fig 8.11(b) – active-LOW decoder (E = 0), NAND গেট (বইয়ে এটাও “(a)” ছাপা)

পেইজ ১৮৮ – Canonical POS Implementation (Fig 8.12)

  • Canonical POS: function-এর ইনপুট decoder-এ দাও। Active-LOW decoder (maxterm দেয়) হলে function-এর maxterm-গুলোর আউটপুট AND করো। Active-HIGH decoder হলে সেগুলো NOR করো।
F₁(A,B,C) = Π(0,3,5,6) F₂(A,B,C) = Π(1,2,3,4)

(a) Active-LOW decoder (E = 0) + AND গেট

(b) Active-HIGH decoder (E = 1) + NOR গেট (বইয়ের ফিগারে ডানেরটা active-HIGH। ক্যাপশনে ভুলে “Figure 10.12” আর দুটোই “(a)” লেখা)

কোনটা নেবে? minterm সংখ্যা 2ⁿ/2-এর কম হলে Fig 8.11 (SOP) ভালো, নইলে Fig 8.12 (POS)। কম সংখ্যক গেট লাগে।
  • Decoder পদ্ধতিতে যেকোনো সার্কিট হয়, কিন্তু অন্য পদ্ধতির সাথে তুলনা করে সেরাটা নিতে হয়। অনেকগুলো আউটপুট আর প্রতিটায় কম minterm/maxterm থাকলে এই পদ্ধতি সবচেয়ে ভালো, কারণ একটা ডিকোডার সবার জন্য শেয়ার হয়।

8.4 Code Converter

  • বিভিন্ন সিস্টেম BCD, Excess-3 ইত্যাদি আলাদা code ব্যবহার করে, তাই এক সিস্টেমের আউটপুট আরেকটার ইনপুট করতে code conversion লাগে। Code converter = combinational circuit, একধরনের encoder। classical method বা MSI দিয়ে বানানো যায়।
  • BCD-to-Excess-3: Excess-3 = BCD + 3। ইনপুট 1010–1111 invalid, তাই এদের আউটপুট don’t care (x) (K-map সরলীকরণে কাজে লাগে)।
