8.1 Introduction ও 8.2.1 Encoder

  • Digital system এ তথ্য binary code এ থাকে। n-bit code দিয়ে 2ⁿ টি আলাদা element বোঝানো যায়। Error detection এও code ব্যবহার হয়।
  • Encoder: discrete input → binary code। Decoder: binary code → discrete output (উল্টো কাজ)।
  • Code converter: এক code থেকে আরেক code (যেমন BCD→Excess-3); এটা encoder এর বিশেষ রূপ।
  • Multiplexing: অনেক information কম channel/line দিয়ে পাঠানো। Demultiplexing: উল্টো, কম line থেকে অনেক unit এ ছড়ানো।
  • MUX/DEMUX লাগে যখন many source → one destination বা one source → many destination path select করতে হয়।

Encoder এর সংজ্ঞা

Encoder একটি combinational circuit যার 2ⁿ (বা কম) input line আর n output line। একসময় শুধু একটি input active থাকে; output সেই input এর binary code দেয়।

  • Active-LOW input: active input = 0, বাকি সব = 1।
  • Active-HIGH input: active input = 1, বাকি সব = 0।

Octal-to-binary encoder = 8-to-3 line encoder। Truth table থেকে Boolean function:

Active-LOW: O₀ = D₁′ + D₃′ + D₅′ + D₇′ = (D₁D₃D₅D₇)′ O₁ = D₂′ + D₃′ + D₆′ + D₇′ = (D₂D₃D₆D₇)′ O₂ = D₄′ + D₅′ + D₆′ + D₇′ = (D₄D₅D₆D₇)′
লেখার নিয়ম: যেসব input এর binary code এ ওই output bit = 1, শুধু সেই input গুলো OR (active-HIGH) বা NAND (active-LOW) করো। যেমন O₀ = 1 হয় ১, ৩, ৫, ৭ এর জন্য (বিজোড় সংখ্যা)।

8.4 Code Converter: BCD to Excess-3

  • বিভিন্ন system এ আলাদা code (BCD, Excess-3 ইত্যাদি) চলে; এক system এর output অন্য system এর input হলে conversion দরকার।
  • Code converter = combinational circuit, encoder এর special type। বানানো যায় classical method (truth table → K-map → gate) বা MSI দিয়ে।

Fig 8.14: Block diagram ও Truth table

BCD এ 1010–1111 invalid, তাই output don't care (X)।

Fig 8.15: K-map (সব ৪টি output)

Rows = B₃B₂, columns = B₁B₀ (Gray order 00, 01, 11, 10)। X গুলো দরকারমতো 1 ধরে বড় group করো। ফল:

E₀ = B₀′ E₁ = B₁′B₀′ + B₁B₀ E₂ = B₂′B₀ + B₂′B₁ + B₂B₁′B₀′ E₃ = B₃ + B₂B₀ + B₂B₁

Fig 8.16: Logic diagram আঁকার ধাপ

  • B₃B₂B₁B₀ প্রত্যেকের জন্য NOT gate (B′ পেতে)।
  • E₀ = সরাসরি B₀ এর NOT output (কোনো gate লাগে না)।
  • E₁: ২টি AND (B₁′B₀′, B₁B₀) → ১টি OR।
  • E₂: ৩টি AND (B₂′B₀, B₂′B₁, B₂B₁′B₀′) → OR।
  • E₃: B₃ সরাসরি + ২টি AND (B₂B₀, B₂B₁) → ৩-input OR।

Fig 8.17: 4-bit Binary Adder দিয়ে

Excess-3 = BCD + binary 3 (0011)। তাই 4-bit adder এর এক input এ BCD, অন্য input এ 0011, C₀ = 0, C₄ unused; output S₃S₂S₁S₀ = E₃E₂E₁E₀।

লিখবে: truth table → K-map → E₀–E₃ equation → logic diagram। বা সংক্ষেপে: Excess-3 = BCD + 3, তাই adder দিয়ে সহজেই হয়।

8.5 BCD-to-7-Segment Display Decoder

  • Decimal দেখার জন্য সবচেয়ে জনপ্রিয় device = 7-segment display (৭টি LED: a, b, c, d, e, f, g)।
  • BCD কে 7-segment code এ convert করতে হয়। Current নিয়ন্ত্রণ করে কিছু segment জ্বলে, কিছু নিভে থাকে। যেমন "6" দেখাতে a, c, d, e, f, g জ্বলে, b নিভে।
  • Decoder 4-bit BCD নিয়ে ঠিক segment গুলো activate করে। এখানে active-LOW output (0 = segment জ্বলবে)। Invalid BCD (1010–1111) এ কোনো segment জ্বলে না, মানে সব output 1।

8.6 Parity Generator ও Checker

  • Parity bit = message এর সাথে একটি extra bit, যাতে মোট 1 এর সংখ্যা odd (odd parity) বা even (even parity) হয়। Error detection এর জন্য।
  • Transmitter এর circuit = parity generator। Receiver এর circuit = parity checker। Checked parity transmitted parity এর সাথে না মিললে error।

Odd Parity Generator (Fig 8.23)

3-bit এ P = 1 হয় যখন data তে 1 এর সংখ্যা even (মোট odd করার জন্য)। এটা EXOR এর complement। বিজোড় সংখ্যক input এ EXOR ও EXNOR সমান, তাই EXNOR ও বলা যায়। 4-bit এ ৮টি minterm এ 0 এর সংখ্যা even; এটা EXNOR, মানে EXOR এর complement।

3-bit: P = (D₂ ⊕ D₁ ⊕ D₀)′ 4-bit: P = (D₃ ⊕ D₂ ⊕ D₁ ⊕ D₀)′ n-bit: P = (Dₙ₋₁ ⊕ Dₙ₋₂ ⊕ … ⊕ D₁ ⊕ D₀)′

Fig 8.24: 4-bit odd parity generator logic

(D₃⊕D₂) ও (D₁⊕D₀) এর ২টি XOR → ৩য় XOR → NOT।

Odd Parity Checker (Fig 8.25, 8.26)

n-bit message = (n−1) bit data + 1 parity bit। Output E = 1 মানে error, E = 0 মানে error নেই।

E = (P ⊕ Dₙ₋₁ ⊕ … ⊕ D₁ ⊕ D₀)′
Fig 8.24 ও 8.26 একই রকম, শুধু P input হিসেবে ঢোকে। তাই একই circuit parity generator ও checker দুটোই হিসেবে চলে। Even parity এর জন্য শেষের NOT বাদ দাও (P = XOR শুধু)।

8.6.2 IC 74180 (8-bit parity generator/checker)

  • Odd ও even দুই parity generate/check করে। Enable input: P_E (even), P_O (odd)। Data D₀–D₇। Output E_E, E_O।
  • True active-HIGH parity: P_E = 1, P_O = 0। True active-LOW parity: P_E = 0, P_O = 1।
  • 9-bit word (৮ bit + parity) check: দুই enable ও একটি inverter ৯ম data input হিসেবে। Active-HIGH parity check এ ৯ম data input P_O তে দাও, আর P_O ও P_E এর মাঝে inverter। Active-LOW parity check এ ৯ম input P_E তে, inverter P_E ও P_O এর মাঝে।

8.7 Multiplexer (MUX)

  • MUX = অনেক input line থেকে এক বাছাই করে একটি output line এ পাঠায়। বাছাই করে address (select) line। সাধারণত 2ⁿ input ও n address line।
  • MUX কে data selector ও বলে।
  • AND gate অংশ decoder এর মতো address decode করে; সাধারণভাবে 2ⁿ-to-1 MUX = n-to-2ⁿ decoder + প্রতি AND এ একটি করে data input + একটি OR gate।

8.7.4 MUX Expansion

বড় MUX বানাতে ছোট MUX এর enable ব্যবহার করা হয়।

Fig 8.33(a): 8×1 = দুটি 4×1 + OR

  • A₂ = 0: M1 enabled, M2 disabled (M2 output 0)। OR এর output = M1 এর selected input।
  • A₂ = 1: M1 disabled (output 0), M2 enabled। Output = M2 এর selected input।
  • উদাহরণ: A₂A₁A₀ = 101 → M2 enabled, A₁A₀ = 01 → M2 এর I₁ = combined এর I₅।

Fig 8.33(b): 16×1 = চারটি 4×1 (M1–M4) + একটি 4×1 (M5)

  • A₃A₂ = 00 → M5 এর output = M1 এর output; 01 → M2; 10 → M3; 11 → M4।
  • M1–M4 এ low-order bit A₁A₀ common। উদাহরণ: A₃A₂A₁A₀ = 0110 → M5 এর I₁ (M2 এর output) → M2 এর I₂ = combined এর I₆।
মনে রাখো: 8×1 = 2×(4×1) + OR, 16×1 = 4×(4×1) + 1×(4×1), 32×1 = 4×(8×1) + 1×(4×1) বা 2×(16×1) + OR।

8.7.5 MUX দিয়ে Combinational Logic

MUX আসলে active-HIGH decoder + OR gate। যে minterm function এ আছে তার input এ 1, নেই তার input এ 0 দাও। Variable গুলো address line এ।

পদ্ধতি ১ (Fig 8.34): n variable → 2ⁿ×1 MUX

উদাহরণ: F(A,B,C,D) = Σ(0,2,3,6,8,9,12,14), 16×1 MUX। A, B, C, D = A₃A₂A₁A₀। I₀, I₂, I₃, I₆, I₈, I₉, I₁₂, I₁₄ এ 1; বাকি সব (I₁, I₄, I₅, I₇, I₁₀, I₁₁, I₁₃, I₁₅) এ 0। Enable E = 0 (active-LOW এ সর্বদা চালু)।

পদ্ধতি ২ (ভালো): n variable → 2ⁿ⁻¹×1 MUX

n−1 টি variable address এ, বাকি একটি (A) MUX এর input এ। Input হয় চারটির একটি: 0, 1, A, A′।

Fig 8.35: F(A,B,C) = Σ(1,3,5,6), 4×1 MUX

B → A₁, C → A₀ (এই ক্রমে)।

  • BC = 00: I₀ = 0 → m₀, m₄ দুটোই 0।
  • BC = 01: I₁ = 1 → m₁, m₅ দুটোই 1।
  • BC = 10: I₂ = A → শুধু m₆ = AB′… (ABC′) =1, m₂ = 0।
  • BC = 11: I₃ = A′ → শুধু m₃ = 1, m₇ = 0।

Implementation table (Fig 8.35c) আঁকার নিয়ম

  1. Function কে Σ minterm form এ লেখো। ক্রম ABCD…, A সবচেয়ে বামে।
  2. MUX input I₀, I₁, … এর নিচে দুই সারিতে minterm লেখো: উপরের সারি (A′) = 0 থেকে 2ⁿ⁻¹−1, নিচের সারি (A) = বাকি অর্ধেক।
  3. Function এর minterm গুলো circle করো। প্রতি column দেখো: দুটোই circle নেই → 0; দুটোই circle আছে → 1; শুধু নিচেরটা circle → A; শুধু উপরেরটা circle → A′।

B, C, D → A₂, A₁, A₀।

I₀=1, I₁=1, I₂=0, I₃=A′, I₄=A′, I₅=0, I₆=0, I₇=A

আঁকার সময়: I₀, I₁ → logic 1; I₂, I₅, I₆ → logic 0; I₃, I₄ → A এর NOT output; I₇ → A।

MUX বনাম Decoder: Decoder পদ্ধতিতে একটি decoder সব output function তৈরি করে, কিন্তু প্রতি output এ একটি external gate লাগে। MUX পদ্ধতিতে ছোট unit, কিন্তু প্রতি output function এ একটি করে MUX। Output কম হলে MUX ভালো; অনেক output হলে decoder দিয়ে IC কম লাগে।

8.8 Demultiplexer (DEMUX)

  • DEMUX = একটি input line এর তথ্য 2ⁿ টি output line এর একটিতে পাঠায়। n টি address line নির্ধারণ করে কোন output।

Fig 8.37: 1-to-4 DEMUX

O₀ = I A₁′A₀′ O₁ = I A₁′A₀ O₂ = I A₁A₀′ O₃ = I A₁A₀

Fig 8.38: Logic diagram

এই circuit আসলে 2-to-4 decoder (active-HIGH output ও active-HIGH enable), যেখানে DEMUX এর input I = enable। আবার active-LOW output ও active-LOW enable সহ 2-to-4 decoder (Fig 8.9) কে 1-to-4 DEMUX হিসেবে ব্যবহার করা যায়, যদি enable E কে input ধরা হয়। শুধু পার্থক্য: unselected output গুলো 1 থাকে।

8.8.3 DEMUX Expansion (Fig 8.39): 1×16 = পাঁচটি 1×4

  • DM1 কে high-order bit A₃A₂ select করে: 00 → O₀ (DM2), 01 → O₁ (DM3), 10 → O₂ (DM4), 11 → O₃ (DM5)। বাইরের input I প্রথমে DM1 এ ঢোকে।
  • নির্বাচিত DEMUX এ low-order bit A₁A₀ (সব DM2–DM5 এ common) নির্ধারণ করে কোন output এ I আসবে।
  • উদাহরণ: A₃A₂A₁A₀ = 0110 → I যায় DM1 এর O₁ → DM3 এর input → A₁A₀ = 10 → DM3 এর O₂ = combined এর O₆।

8.8.4 DEMUX দিয়ে Combinational Logic (Fig 8.40)

I = 1 দিলে DEMUX = active-HIGH decoder। তখন পদ্ধতি decoder এর মতোই: যে minterm function এ আছে সেই output গুলো OR করো।

F₁(A,B,C) = Σ(1,2,4,7) = O₁ + O₂ + O₄ + O₇ F₂(A,B,C) = Σ(0,5,6,7) = O₀ + O₅ + O₆ + O₇

1×8 DEMUX, I = 1, A₂A₁A₀ = ABC, আর দুটি OR gate (একটি F₁ এর, একটি F₂ এর)।

Exercises ও Further Reading

Decoder সংক্রান্ত প্রশ্ন (8.3–8.13, 8.17, 8.19, 8.20) বাদ। বাকি প্রশ্নের কোনটায় কোন পদ্ধতি:

  • 8.1, 8.2 Encoder (decimal-to-BCD, Excess-3, hex-to-binary, 12-to-4): প্রতি output bit এর জন্য যেসব input এ ওই bit = 1, সেগুলো OR/NAND করো। 8.2 এ output inverted (শেষে NOT)।
  • 8.14 Excess-3-to-BCD (classical): ১০টি valid input (0011–1100), বাকি X → K-map। 8.15 Adder দিয়ে: Excess-3 থেকে 0011 বিয়োগ, অর্থাৎ +1101 (−3 এর 2's complement) যোগ করো, C₀ = 0।
  • 8.16, 8.18 7-segment (active-HIGH / hex): 8.5 এর মতো, active-HIGH এ lit segment = 1। Hex এ ১৬ input ই valid।
  • 8.21, 8.22 Parity: 3-bit odd generator/checker (XOR + NOT); n-bit even: XOR chain, NOT ছাড়া।
  • 8.23 2-to-4 decoder (active-HIGH) + ৪টি AND (I_k দিয়ে) + OR = 4×1 MUX। 8.24 Enable active-HIGH: AND এ E (NOT ছাড়া) যোগ।
  • 8.25–8.27, 8.33 MUX expansion: 8×1 = দুটি 4×1 (active-LOW E) + OR; 32×1 = 4×(8×1) + 4×1; 32×1 = 2×(16×1) + OR; 40×1 = পাঁচটি 8×1 + একটি 8×1 (৫টি input ব্যবহার)।
  • 8.28, 8.30, 8.31, 8.32, 8.29 MUX দিয়ে function: 8.28 (16×1: minterm এ 1; বা 8×1 বইয়ের Fig 8.36), 8.30 (a) 16×1, (b) 8×1 এ implementation table পদ্ধতি, 8.31 Full adder (Sum = Σ(1,2,4,7), Carry = Σ(3,5,6,7), দুটি 4×1 বা 8×1), 8.29 x, y কে address এ দিয়ে input নির্ণয়।
  • 8.34, 8.35 DEMUX expansion: 1×32 = 1×4 + চারটি 1×8; 1×40 = 1×8 (প্রথম স্তর, ৫টি output) + পাঁচটি 1×8।
