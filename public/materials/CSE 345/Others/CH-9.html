0. Standard Textbook vs. Classroom Notes Check (Important Clarifications)

Ensuring 100% accuracy across standard Morris Mano conventions and handwritten lecture notes

বাংলা নোট ও সতর্কতা (ক্লাস লেকচার ও বইয়ের পার্থক্য):

  • ১. Available বনাম Desired ফ্লিপ-ফ্লপ উল্টে ফেলা: হাতে লেখা নোটে শিক্ষার্থীরা প্রায়ই "SR to JK" বলতে কোনটি আছে (Available) আর কোনটি বানাতে হবে (Desired) তা গুলিয়ে ফেলে। মনে রাখবে: "A to B" মানে A হলো Available (যা হাতে আছে) এবং B হলো Desired (যা বানাতে হবে)।
  • ২. K-Map এ Gray Code এর ক্রম: ৩-ভেরিয়েবল K-Map-এ কলামের মান সবসময় 00, 01, 11, 10 হয়। অনেকেই ভুল করে 00, 01, 10, 11 লিখে ফেলে—এতে পুরো সমীকরণ ভুল হয়ে যায়।
  • ৩. S এবং R ইনপুটের ক্রম: কিছু বইয়ে Excitation Table-এ S R ক্রম থাকে, আবার কিছু ক্লাস নোটে R S থাকে। এই নোটে স্ট্যান্ডার্ড (S, R) এবং (J, K) ক্রম অনুসরণ করা হয়েছে এবং প্রতিটি কলাম স্পষ্ট করে দেখানো হয়েছে।
  • ৪. NAND বনাম NOR Latch: বেসিক NOR ল্যাচে S=1, R=1 হলো Forbidden/Invalid অবস্থা, কিন্তু NAND ল্যাচে (Active-Low) S'=0, R'=0 হলো Invalid অবস্থা। পরীক্ষায় সবসময় Active-High (NOR ভিত্তিক) ধরা হয় যদি না উল্লেখ থাকে।

Key Technical Verifications & Common Handwriting Errors:

  • Conversion Direction Rule ("X to Y"): In "Convert X Flip-Flop to Y Flip-Flop", X is the Available (Given) FF and Y is the Desired (Target) FF. You always write the Characteristic Table of Y and the Excitation Table of X.
  • K-Map Column Ordering: Columns must follow Gray Code (00, 01, 11, 10). Mixing binary order (10 before 11) is the #1 cause of wrong Boolean expressions in handwritten scripts.
  • Don't Care ('X') Usage: Don't cares in K-maps are only grouped with 1s if they help form a larger power-of-2 group (quad or pair). Never group 'X's alone.
  • Clock Edge Notation: A triangle (>) on the CLK pin indicates positive-edge triggering; a bubble with a triangle (o>) indicates negative-edge triggering.
Topic 01

1. Sequential Circuits & Comparison with Combinational Circuits

সহজ বাংলায় বুঝি (Basic Concept):

ডিজিটাল ইলেকট্রনিক্সে লজিক সার্কিট প্রধানত দুই প্রকার: Combinational Circuit এবং Sequential Circuit।

Combinational Circuit (যেমন: Adder, Multiplexer) এর আউটপুট শুধুমাত্র বর্তমান ইনপুটের (Present Input) ওপর নির্ভর করে। এর কোনো মেমোরি বা স্মৃতিশক্তি নেই। যেমন: ক্যালকুলেটরে ২+২ চাপলে ৪ দেখাবে—আগে কী চেপেছিলে তা সে মনে রাখে না।

অন্যদিকে, Sequential Circuit হলো এমন সার্কিট যার আউটপুট বর্তমান ইনপুট (Present Input) এবং পূর্ববর্তী অবস্থা বা মেমোরি (Past Output / Present State)—এই দুটোর ওপরই নির্ভর করে। অর্থাৎ, এটি তথ্য ধরে রাখতে (Store করতে) পারে। যেমন: টিভির রিমোটের চ্যানেল আপ বাটন—বর্তমানে ৫ নম্বর চ্যানেলে থাকলে বাটন চাপলে ৬ হবে, অর্থাৎ সার্কিটটিকে মনে রাখতে হচ্ছে যে আগে ৫ নম্বর চ্যানেল চলছিল!

মূল সূত্র: Sequential Circuit = Combinational Circuit + Memory Element (Latch / Flip-Flop)

Exam-Ready Answer (English — 5 Marks):

Definition: A Sequential Circuit is a digital logic circuit whose output at any instant depends not only on the present external inputs but also on the past sequence of inputs (i.e., the present state stored in memory elements). It consists of a combinational logic network coupled with memory elements (Latches or Flip-Flops) via a feedback path.

Feature Combinational Circuit Sequential Circuit
Output Dependency Depends only on present inputs. Depends on present inputs + past outputs (present state).
Memory Element No memory element required. Requires memory elements (Latches / Flip-Flops).
Feedback Path No feedback path exists. Feedback path from output to input is mandatory.
Clock Signal Not required. Required for synchronous sequential circuits.
Examples Half Adder, Full Adder, MUX, Decoder, Encoder. Flip-Flops, Counters, Shift Registers, Memory Units.
Types of Sequential Circuits:
  • Asynchronous Sequential Circuit: Output changes immediately whenever inputs change (no clock signal; uses unclocked Latches).
  • Synchronous Sequential Circuit: Output changes only at discrete instants synchronized by a master Clock (CLK) pulse (uses Flip-Flops).
Topic 02

2. Latches (SR Latch & Gated D Latch)

সহজ বাংলায় বুঝি (Latch কী এবং কীভাবে কাজ করে?):

Latch (ল্যাচ) হলো ডিজিটাল মেমোরির সবচেয়ে ক্ষুদ্র একক (Basic 1-bit Memory Element)। এটি ১ বিট তথ্য (0 অথবা 1) ধরে রাখতে পারে। ল্যাচ হলো Level-Triggered—অর্থাৎ এর Enable (বা Clock) পিন যতক্ষণ HIGH (1) থাকবে, ইনপুট বদলালে সাথে সাথে আউটপুটও বদলে যাবে।

SR Latch (Set-Reset Latch): দুটি NOR গেট (অথবা দুটি NAND গেট) ক্রস-কাপলড (Cross-coupled) করে SR Latch তৈরি করা হয়। এর দুটি ইনপুট: S (Set) এবং R (Reset), এবং দুটি আউটপুট: Q এবং Q' (যা সবসময় Q-এর বিপরীত)।

  • S = 0, R = 0 (Hold / No Change): সার্কিট আগের মানটাই ধরে রাখবে (Q যা ছিল তাই থাকবে)।
  • S = 1, R = 0 (Set): আউটপুট সেট হয়ে Q = 1 হবে (এবং Q' = 0)।
  • S = 0, R = 1 (Reset): আউটপুট রিসেট হয়ে Q = 0 হবে (এবং Q' = 1)।
  • S = 1, R = 1 (Invalid / Forbidden): একই সাথে Set এবং Reset করা সম্ভব নয়! এতে Q এবং Q' দুটোই 0 হয়ে যায়, যা লজিকবিরোধী। তাই এই অবস্থা নিষিদ্ধ।

D Latch (Data / Transparent Latch): SR Latch-এর Invalid অবস্থা (S=1, R=1) দূর করার জন্য S ও R-এর মাঝে একটি NOT গেট বসিয়ে D Latch তৈরি করা হয়। ফলে D=1 দিলে Q=1 এবং D=0 দিলে Q=0 হয়।

Exam-Ready Answer (English — 5 Marks):

A Latch is a bistable multivibrator (1-bit memory element) that operates asynchronously or with a level-sensitive Enable signal. Because it is level-triggered, its output responds continuously to input changes as long as the Enable signal is active.

NOR-Based SR Latch Logic Diagram
S R Q(next) Q(next) State / Operation
0 0 Q Q No Change (Hold)
0 1 0 1 Reset
1 0 1 0 Set
1 1 0 0 Invalid / Forbidden
Key Difference: Latch vs. Flip-Flop

A Latch is level-triggered (checks inputs continuously while Enable = 1), whereas a Flip-Flop is edge-triggered (samples inputs only at the exact rising or falling transition edge of the Clock signal).

Topic 03

3. Flip-Flops: SR, D, JK, and T Flip-Flops

সহজ বাংলায় চারটি Flip-Flop-এর পরিচয়:

Flip-Flop হলো Clock-controlled (Edge-triggered) ১-বিট মেমোরি ডিভাইস। এটি কেবল Clock পালসের এজ-এ (যেমন 0 থেকে 1 হওয়ার মুহূর্তে) ইনপুট গ্রহণ করে আউটপুট আপডেট করে। সিলেবাসে ৪ ধরনের Flip-Flop পড়তে হয়:

  1. SR Flip-Flop (Set-Reset): ক্লকড SR ল্যাচ। S=1, R=0 হলে আউটপুট 1 (Set) হয়; S=0, R=1 হলে আউটপুট 0 (Reset) হয়; S=0, R=0 হলে আগের মান থাকে; আর S=1, R=1 হলো Invalid/Indeterminate অবস্থা।
  2. D Flip-Flop (Data / Delay): এর মাত্র ১টি ইনপুট D। ক্লক এলে ইনপুট D-তে যা থাকে, আউটপুট Q(n+1)-এ ঠিক তাই চলে যায় (Q(n+1) = D)। এটি রেজিস্টার ও ডেটা স্টোরেজে ব্যবহৃত হয়।
  3. JK Flip-Flop (Jack-Kilby): এটি SR Flip-Flop-এর উন্নত সংস্করণ। এখানে SR-এর Invalid সমস্যা সমাধান করা হয়েছে! J=1, K=0 হলে Set (1), J=0, K=1 হলে Reset (0), J=0, K=0 হলে Hold, এবং J=1, K=1 হলে আউটপুট Toggle (উল্টে) যায় (অর্থাৎ আগে 0 থাকলে 1 হবে, আর 1 থাকলে 0 হবে)।
  4. T Flip-Flop (Toggle): JK Flip-Flop-এর J এবং K ইনপুট দুটিকে একসাথে যুক্ত করে T ইনপুট বানানো হয়। T=0 হলে আউটপুট অপরিবর্তিত থাকে (Hold), এবং T=1 হলে আউটপুট উল্টে যায় (Toggle: Q(n+1) = Q')। এটি Counter তৈরিতে সবচেয়ে বেশি ব্যবহৃত হয়।

1. SR Flip-Flop

Q(n+1) = S + R'Q

Inputs: S (Set), R (Reset), CLK. Suffers from undefined state when S = R = 1.

2. D (Data) Flip-Flop

Q(n+1) = D

Single data input D. Eliminates S=R=1 condition; next state directly follows D at clock edge.

3. JK Flip-Flop

Q(n+1) = JQ' + K'Q

Universal FF. J=Set, K=Reset. When J = K = 1, output toggles: Q(n+1) = Q'(n).

4. T (Toggle) Flip-Flop

Q(n+1) = T ⊕ Q

Obtained by tying J and K together. T=0 holds state; T=1 complements (toggles) state.

Topic 04 • Important 5-Mark Exam Question

4. Race-Around Condition & Master-Slave JK Flip-Flop

সহজ বাংলায় বুঝি (Race-Around কী এবং কেন হয়?):

Race-Around Condition: একটি Level-Triggered JK Flip-Flop-এ যখন J = 1 এবং K = 1 থাকে, তখন আউটপুট Toggle করে (অর্থাৎ 0 থেকে 1 বা 1 থেকে 0 হয়)। এখন ধরো, Clock পালসটি যতক্ষণ HIGH (CLK = 1) থাকে তার সময়কাল যদি Flip-Flop-এর ভেতরের গেটগুলোর প্রোপাগেশন ডিলে (Propagation Delay, tpd) থেকে বেশি হয়, তবে কী ঘটবে?

আউটপুট একবার Toggle হয়ে 0 থেকে 1 হওয়ার পরও যেহেতু CLK এখনো 1 আছে, তাই নতুন আউটপুট 1 আবার ইনপুটে ফিডব্যাক হয়ে আউটপুটকে আবার 0 করে দেবে! এভাবে একটি মাত্র Clock পালসের মধ্যেই আউটপুট 0 → 1 → 0 → 1 → 0... করে অনবরত কাঁপতে বা দৌড়াতে (Oscillate করতে) থাকবে। ক্লক শেষে আউটপুট 0 হবে নাকি 1 হবে তা আগে থেকে বলা অসম্ভব হয়ে পড়ে। এই অনিশ্চিত অবস্থাকেই Race-Around Condition বলে।

সমাধান (Master-Slave JK Flip-Flop): এই সমস্যা দূর করতে দুটি JK Flip-Flop সিরিজে যুক্ত করা হয়। প্রথমটিকে বলে Master এবং দ্বিতীয়টিকে বলে Slave। Master সরাসরি CLK পায়, আর Slave একটি NOT গেটের মাধ্যমে উল্টো ক্লক (CLK') পায়। ফলে:
  • যখন CLK = 1, তখন Master কাজ করে (Slave বন্ধ থাকে), তাই আউটপুট একবারই বদলায়।
  • যখন CLK = 0, তখন Master বন্ধ হয় এবং Slave কাজ করে (Master-এর মান Slave-এ কপি হয়)। ফলে এক ক্লক সাইকেলে আউটপুট কেবল একবারই Toggle করে!

Exam-Ready Answer (English — 5 Marks):

1. Race-Around Condition: In a level-triggered JK flip-flop, when J = 1, K = 1, and CLK = 1, the output toggles after a propagation delay (tpd). If the clock pulse width (tw) is greater than the propagation delay (tw > tpd), the toggled output feeds back to the input while the clock is still HIGH, causing the output to toggle repeatedly (0 → 1 → 0 → 1...) within a single clock pulse. At the end of the clock pulse, the final state becomes unpredictable. This phenomenon is called the Race-Around Condition.

2. Prevention using Master-Slave JK Flip-Flop: A Master-Slave JK flip-flop cascades two clocked SR/JK flip-flops: a Master driven by CLK and a Slave driven by inverted CLK. When CLK = 1, the Master is enabled and samples J & K, while the Slave is disabled. When CLK goes to 0, the Master is isolated and the Slave is enabled, copying the Master's state to the final output Q. Since the feedback loop is broken during any single half-cycle, racing is completely eliminated.

Topic 05 • Core Foundation for Conversions

5. Understanding Q(n) vs Q(n+1), Characteristic vs Excitation Tables & Don't Care (X)

সহজ বাংলায় মূল ধারণাগুলো ক্লিয়ার করি:

১. Q(n) এবং Q(n+1) কী?
ধরো ঘড়ির কাঁটা (Clock pulse) এখন টিক দেওয়ার ঠিক আগের মুহূর্তে ফ্লিপ-ফ্লপের আউটপুটে যে মান জমা আছে, তাকে বলে Present State বা Q(n) (বর্তমান অবস্থা)। আর Clock pulse আসার পর ফ্লিপ-ফ্লপের আউটপুট বদলে যে নতুন মান তৈরি হয়, তাকে বলে Next State বা Q(n+1) (পরবর্তী অবস্থা)।

২. Characteristic Table বনাম Excitation Table (পার্থক্য কী?):
• Characteristic Table (বৈশিষ্ট্য সারণি): এখানে ইনপুটগুলো (যেমন J, K) এবং বর্তমান অবস্থা Q(n) দেওয়া থাকে; তোমাকে বের করতে হয় পরবর্তী অবস্থা Q(n+1) কী হবে? (অর্থাৎ: ইনপুট দিলে আউটপুট কী হবে?)।
• Excitation Table (উদ্দীপনা সারণি): এটি ঠিক উল্টো! এখানে বর্তমান অবস্থা Q(n) থেকে পরবর্তী অবস্থা Q(n+1)-এ যেতে হলে ইনপুট পিনগুলোতে (যেমন S, R) কী মান দিতে হবে তা লেখা থাকে। (অর্থাৎ: আউটপুট 0 থেকে 1 করতে চাইলে ইনপুটে কী দেবো?)।

৩. Don't Care Condition ('X') কীভাবে আসে? (সহজ উদাহরণ):
ধরো তোমার কাছে একটি SR Flip-Flop আছে। বর্তমানে এর আউটপুট Q(n) = 0 এবং তুমি চাও ক্লকের পর আউটপুট Q(n+1) = 0-ই থাকুক (0 → 0)।
তুমি দুইভাবে এটি করতে পারো:
(ক) S = 0, R = 0 (No Change) দিলে 0 থেকে 0 থাকবে।
(খ) S = 0, R = 1 (Reset) দিলেও আউটপুট 0 হবে!
লক্ষ্য করো: উভয় ক্ষেত্রেই S = 0 নিশ্চিতভাবে দিতে হবে, কিন্তু R-এর মান 0 হোক বা 1 হোক—আউটপুট 0-ই আসছে! তাই R-এর মান নিয়ে আমাদের কোনো মাথাব্যথা নেই; আমরা R-এর ঘরে লিখি X (Don't Care)। এজন্যই 0 → 0 ট্রানজিশনে SR-এর Excitation হয় S = 0, R = X!

How Final Equations Become Circuit Connections (Golden Rule):

In any conversion, the Available Flip-Flop sits at the output stage. Its inputs (e.g., S and R) are driven by combinational logic gates whose inputs come from the External Desired Inputs (e.g., J, K) and the Feedback Outputs (Q and Q) of the Available Flip-Flop! For example, S = J · Q literally means: take an AND gate, connect external input J and feedback wire Q into it, and feed its output into pin S.
