CHAPTER 1: INTRODUCTION TO DIGITAL SYSTEMS

1.1 Introduction

When most of us hear the term digital, we immediately think of a "digital calculator" or "digital computer". However, calculators and computers represent only one of the many applications of digital circuits and principles. Digital circuits are widely used in video games, microwave ovens, automobile control systems, as well as test equipment like digital voltmeters, signal generators, and oscilloscopes.

সহজ ভাষায় ব্যাখা: আমরা "ডিজিটাল" শুনলেই কম্পিউটার বা ক্যালকুলেটরের কথা ভাবি। কিন্তু ডিজিটাল সার্কিট শুধু কম্পিউটারেই সীমাবদ্ধ নয়। আমাদের বাসাবাড়ির ওভেন, ওয়াশিং মেশিন, আধুনিক গাড়ি, এমনকি ডিজিটাল ঘড়ি ও টিভিতেও ডিজিটাল সার্কিট ব্যবহৃত হয়। আগে যেখানে এনালগ প্রযুক্তি ছিল (যেমন ক্যাসেট প্লেয়ার বা পুরানো রেডিও), এখন সেখানে ডিজিটাল টেকনোলজি ব্যবহার করা হয়।

1.2 Digital and Analog Systems

In physical systems, quantities are measured, monitored, recorded, or manipulated arithmetically. Numerical values of quantities are represented in two basic ways:

  • Analog Representation: A quantity is represented by a continuously proportional physical signal (voltage, current, or meter movement). It varies over a continuous range of values.
  • Digital Representation: Quantities are represented not by proportional signals, but by discrete symbols called digits. Values change in discrete steps rather than continuously.
বাস্তব জীবনের উদাহরণ (Real-Life Example):

Analog Example: গাড়ির স্পিডোমিটার (Speedometer)। গাড়ি যখন ১-১০-৫০ কিমি/ঘণ্টা গতি বাড়ায়, তার কাঁটাটি ০ থেকে ১০০ এর মধ্যে যেকোনো মান (যেমন ৪২.৫, ৪২.৫৭৩...) মসৃণভাবে অতিক্রম করে।

Digital Example: ডিজিটাল ঘড়ি (Digital Watch)। সময় মসৃণভাবে পরিবর্তন হলেও ডিজিটগুলো লাফিয়ে লাফিয়ে বদলায় (যেমন ১০:১৫:০১ এর পর সরাসরি ১০:১৫:০২)। মাঝখানের ১০:১৫:০১.৫ সময়টি ঘড়ির স্ক্রিনে আলাদা দেখায় না।

Advantages of Digital Techniques

Why are digital techniques replacing analog techniques across modern engineering?

  1. Easier to Design: Exact voltage/current values are not critical; only LOW or HIGH states matter.
  2. Easy Information Storage: Special circuits (latches, memories) can hold binary data indefinitely.
  3. Greater Accuracy and Precision: Precision is increased simply by adding more binary digits (bits).
  4. Programmable Operation: System function can be altered by simply changing stored software/instructions.
  5. Less Affected by Noise: Spurious electrical noise doesn't corrupt binary states unless it is huge.
  6. Higher Integration (IC Chips): Millions of logic components fit on tiny silicon chips.

1.3 Binary Numbers in Digital Systems

Digital electronic devices naturally operate in two stable states (e.g., ON/OFF, High/Low voltage, Magnetized/Demagnetized). Because they have two states, they are inherently binary. The binary number system contains only two digits: $0$ and $1$.

1.4 Binary Logic

Binary logic deals with binary variables (which take on values $0$ or $1$) and logical operations that assume logical meaning. It forms the foundation of Boolean Algebra.

1.4.1 Definition of Binary Logic

Binary variables are designated by letters ($A, B, C, x, y, z$). There are 3 fundamental logical operations:

  • AND Operation ($\cdot$ or absence of operator): $z = x \cdot y$ or $z = xy$. Output $z=1$ if and only if both $x=1$ and $y=1$. Otherwise, $z=0$.
  • OR Operation ($+$): $z = x + y$. Output $z=1$ if $x=1$ OR $y=1$ OR both are $1$. Output $z=0$ only if both $x=0$ and $y=0$.
  • NOT Operation (' or $\overline{\text{X}}$): $z = x'$ or $z = \bar{x}$. Inverts the variable. If $x=1$, then $z=0$. If $x=0$, then $z=1$.

1.4.2 Truth Table

A Truth Table is a tabular representation listing all possible combinations of input binary variables alongside their corresponding output binary logic result.

Inputs Outputs

1.5 Integrated Circuits (ICs)

Logic gates are fabricated on silicon semiconductor chips called Integrated Circuits (ICs). Depending on the density of gates inside a single silicon package, ICs are broadly classified into:

  • SSI (Small-Scale Integration): Contains fewer than 10 or 12 logic gates (e.g., basic gate ICs like 7400).
  • MSI (Medium-Scale Integration): Contains 10 to 100 logic gates (e.g., decoders, adders, counters, multiplexers).
  • LSI (Large-Scale Integration): Contains 100 to thousands of logic gates (e.g., small memories, microprocessors).
  • VLSI (Very Large-Scale Integration): Contains thousands to millions of gates (e.g., modern CPUs, GPUs, RAMs).

CHAPTER 2: NUMBER SYSTEMS AND CODES

2.1 Introduction

Digital computers and digital systems store and compute data using various number bases (Radix $r$) and coded representations. In this chapter, we explore positional number systems, mathematical complements, binary, octal, hexadecimal representations, arithmetic operations, and discrete binary coding schemes.

2.2 Number Systems

A positional number system uses a base or radix $r$. The general positional weighted representation of a number $(N)_r$ with $n$ integer digits and $m$ fractional digits is expressed as:

$$(N)_r = d_{n-1} r^{n-1} + d_{n-2} r^{n-2} + \dots + d_1 r^1 + d_0 r^0 + d_{-1} r^{-1} + \dots + d_{-m} r^{-m} = \sum_{i=-m}^{n-1} d_i r^i$$

Where:

  • $r$ = Base or Radix of the system ($r > 1$)
  • $d_{n-1}$ = Most Significant Digit (MSD) with highest positional weight $r^{n-1}$
  • $d_{-m}$ = Least Significant Digit (LSD) with lowest positional weight $r^{-m}$
  • $0 \le d_i \le (r-1)$
উদাহরণ সহ ব্যাখা: যেমন ডেসিমেল সংখ্যা $(2356.3294)_{10}$
$= 2\times10^3 + 3\times10^2 + 5\times10^1 + 6\times10^0 + 3\times10^{-1} + 2\times10^{-2} + 9\times10^{-3} + 4\times10^{-4}$
$= 2000 + 300 + 50 + 6 + 0.3 + 0.02 + 0.009 + 0.0004 = 2356.3294$

2.3 Complements

Complements are mathematical tools used in digital computers to simplify subtraction operations by converting subtraction into simple addition. For any base-$r$ system, there are two types of complements:

  1. The $r$'s Complement (Diminished Radix Complement + 1)
  2. The $(r-1)$'s Complement (Diminished Radix Complement)

2.3.1 The $r$'s Complement

Given a positive number $N$ in base $r$ with an integer part of $n$ digits, the $r$'s complement of $N$ is defined as:

$$\text{The } r\text{'s complement of } N = \begin{cases} r^n - N & \text{if } N \neq 0 \\ 0 & \text{if } N = 0 \end{cases}$$
10's Complement Examples (Decimal, $r=10$):

1. 10's complement of $52520$ ($n=5$ digits): $10^5 - 52520 = 100000 - 52520 = \mathbf{47480}$

2. 10's complement of $0.3267$ ($n=0$ integer digits): $10^0 - 0.3267 = 1 - 0.3267 = \mathbf{0.6733}$

3. 10's complement of $25.639$ ($n=2$ integer digits): $10^2 - 25.639 = 100 - 25.639 = \mathbf{74.361}$

Shortcut Rule for 10's Complement: Leave all least significant zeros unchanged, subtract the first non-zero digit from 10, and subtract all remaining higher digits from 9.

2.3.2 The $(r-1)$'s Complement

Given a positive number $N$ in base $r$ with integer part $n$ digits and fraction part $m$ digits:

$$\text{The } (r-1)\text{'s complement of } N = r^n - r^{-m} - N$$
9's Complement Examples (Decimal, $r=10, r-1=9$):

1. 9's complement of $52520$ ($n=5, m=0$): $10^5 - 10^0 - 52520 = 99999 - 52520 = \mathbf{47479}$

2. 9's complement of $0.3267$ ($n=0, m=4$): $10^0 - 10^{-4} - 0.3267 = 0.9999 - 0.3267 = \mathbf{0.6732}$

3. 9's complement of $25.639$ ($n=2, m=3$): $10^2 - 10^{-3} - 25.639 = 99.999 - 25.639 = \mathbf{74.360}$

Shortcut Rule for 9's Complement: Subtract every individual digit of the decimal number from 9.

Note: $r\text{'s complement} = (r-1)\text{'s complement} + r^{-m}$. Complement of a complement restores the original number!

2.3.3 Subtraction with $r$'s Complement

To compute $M - N$ (where $M, N > 0$ in base $r$):

  1. Add the $r$'s complement of subtrahend $N$ to minuend $M$: $\text{Sum} = M + (r^n - N)$.
  2. Inspect the result for an End Carry:
    • If End Carry occurs: Discard the carry. The remaining result is positive: $M - N$.
    • If NO End Carry occurs: Result is negative. Take the $r$'s complement of the sum and place a minus sign in front: $-(N - M)$.
Step-by-Step Examples:

Example 1: $72532 - 3250$ (5 digits: $03250$)

10's complement of $03250$ is $96750$.

Add: $72532 + 96750 = \mathbf{(1)}69282 \implies$ End carry occurs! Discard carry $\implies \mathbf{+69282}$.


Example 2: $3250 - 72532 \implies 03250 - 72532$

10's complement of $72532$ is $27468$.

Add: $03250 + 27468 = \mathbf{30718} \implies$ NO end carry!

Take 10's complement of $30718 \implies 69282$. Result is $\mathbf{-69282}$.

2.3.4 Subtraction with $(r-1)$'s Complement

To compute $M - N$ using $(r-1)$'s complement:

  1. Add $(r-1)$'s complement of $N$ to minuend $M$.
  2. Inspect for End Carry:
    • If End Carry occurs: Add the carry to the Least Significant Digit (LSD). This process is called End-Around Carry!
    • If NO End Carry occurs: Take the $(r-1)$'s complement of the result and add a minus sign.
Step-by-Step Example (End-Around Carry):

$72532 - 03250$

9's complement of $03250 = 96749$.

Sum $= 72532 + 96749 = \mathbf{(1)} 69281$.

Add End-Around Carry: $69281 + 1 = \mathbf{69282}$.

2.4.2 Binary to Decimal Conversion

Expand using powers of 2:

$$(1010.011)_2 = 1\times2^3 + 0\times2^2 + 1\times2^1 + 0\times2^0 + 0\times2^{-1} + 1\times2^{-2} + 1\times2^{-3}$$ $$= 8 + 0 + 2 + 0 + 0 + 0.25 + 0.125 = \mathbf{(10.375)_{10}}$$

2.4.3 Decimal to Binary Conversion

For integer part: Successive Division by 2 (collect remainders bottom-up).
For fractional part: Successive Multiplication by 2 (collect integer carries top-down).

Conversion of $(13.6875)_{10}$ to Binary:

Integer Part (13):

  • $13 \div 2 = 6$, remainder $1$ (LSB)
  • $6 \div 2 = 3$, remainder $0$
  • $3 \div 2 = 1$, remainder $1$
  • $1 \div 2 = 0$, remainder $1$ (MSB)
  • $(13)_{10} = (\mathbf{1101})_2$

Fractional Part (0.6875):

  • $0.6875 \times 2 = 1.375 \implies$ Integer part $1$ (MSB)
  • $0.375 \times 2 = 0.75 \implies$ Integer part $0$
  • $0.75 \times 2 = 1.50 \implies$ Integer part $1$
  • $0.50 \times 2 = 1.00 \implies$ Integer part $1$ (LSB)
  • $(0.6875)_{10} = (\mathbf{.1011})_2$

Combined Result: $(13.6875)_{10} = \mathbf{(1101.1011)_2}$

2.4.4 2's Complement of Binary Numbers

Definition: $2^n - N$. Shortcut Rule: Leave all LSB zeros and the first '1' bit unchanged; invert all subsequent higher significant bits ($0 \to 1, 1 \to 0$).

Example: 2's complement of $(101100)_2 \implies \mathbf{010100}_2$.

2.4.5 1's Complement of Binary Numbers

Definition: $(2^n - 2^{-m} - N)$. Rule: Simply invert all bits ($1 \to 0, 0 \to 1$).

Example: 1's complement of $(101100)_2 \implies \mathbf{010011}_2$.

Relationship: $\text{2's Complement} = \text{1's Complement} + 1$.

2.5.5 Signed Binary Numbers

In signed binary representation, the Most Significant Bit (MSB) acts as the Sign Bit ($0 = \text{Positive}$, $1 = \text{Negative}$). There are three forms:

  1. Sign-Magnitude Form: MSB = Sign bit, remaining bits = absolute magnitude.
    Disadvantage: Dual representation of zero ($+0 = 0000$, $-0 = 1000$). Range for $n$ bits: $-(2^{n-1}-1)$ to $+(2^{n-1}-1)$.
  2. 1's Complement Form: Negative number formed by taking 1's complement of positive number.
    Disadvantage: Dual representation of zero ($+0 = 0000$, $-0 = 1111$). Range: $-(2^{n-1}-1)$ to $+(2^{n-1}-1)$.
  3. 2's Complement Form: Negative number formed by taking 2's complement of positive number.
    Advantage: Unique zero (0000). Extra negative number representation! Range for $n$ bits: $\mathbf{-2^{n-1}}$ to $\mathbf{+(2^{n-1}-1)}$. Widely used in all digital computers!

2.5.6 1's Complement Binary Arithmetic

To subtract $M - N$: Add 1's complement of subtrahend $N$ to $M$. If End Carry generated, add it back to LSB (End-Around Carry). If End Carry = 0, result is negative and in 1's complement form.

2.5.7 2's Complement Binary Arithmetic & Overflow

To subtract $M - N$: Add 2's complement of subtrahend $N$ to $M$.

  • If End Carry generated $\implies$ Discard carry. Result is positive.
  • If NO End Carry generated $\implies$ Result is negative and in 2's complement form.
8-bit 2's Complement Arithmetic Examples:

Example 1 ($48 - 23 = +25$):

$+48 = 00110000$, $-23 = 11101001$ (2's comp of 23)

Sum $= 00110000 + 11101001 = \mathbf{(1)}00011001 \implies$ Discard Carry $\implies \mathbf{+25}$.


Example 2 ($23 - 48 = -25$):

$+23 = 00010111$, $-48 = 11010000$ (2's comp of 48)

Sum $= 00010111 + 11010000 = \mathbf{11100111} \implies$ No Carry. Take 2's complement $\implies -00011001 = \mathbf{-25}$.

Overflow Detection Rule (ওভারফ্লো বোঝার নিয়ম):
১. যদি দুটি বিপরীত চিহ্নের (Opposite Sign) সংখ্যার মধ্যে যোগ/বিয়োগ করা হয়, তবে কখনো Overflow হতে পারে না।
২. যদি একই চিহ্নের (Same Sign) দুটি সংখ্যা যোগ করা হয়, এবং ফলাফল যদি বিপরীত চিহ্নের চলে আসে (যেমন: দুটি Positive যোগ করে MSB 1 বা Negative আসল), তবে Overflow ঘটেছে! অর্থাৎ ফলাফল ৮-বিটের সীমার মধ্যে আঁটছে না।

2.6 Octal Number System

Base $r = 8$. Digits used: $0, 1, 2, 3, 4, 5, 6, 7$. Weights are powers of $8^i$.

2.6.1 - 2.6.3 Octal Representations & Conversions

Octal to Decimal: Multiply by weights $8^i$.
$(6327.4051)_8 = 6\times8^3 + 3\times8^2 + 2\times8^1 + 7\times8^0 + 4\times8^{-1} + 0\times8^{-2} + 5\times8^{-3} + 1\times8^{-4} = \mathbf{(3287.5100098)_{10}}$

Decimal to Octal: Divide integer part by $8$, multiply fraction by $8$.

2.6.4 & 2.6.5 Octal $\leftrightarrow$ Binary Conversions

Each octal digit maps directly to a 3-bit binary pattern!

Example: $(736.42)_8 \implies (111 \ 011 \ 110 \ . \ 100 \ 010)_2 = \mathbf{(111011110.100010)_2}$.

Binary to Octal: Group binary bits into sets of 3 starting from binary point (pad zeros if necessary).

2.6.8 Application of Octal System

Shortens long binary strings for human operators. Entering 376 in octal is much less error-prone than entering 011111110 in binary.

Base $r = 16$. Digits used: $0-9$ and $A(10), B(11), C(12), D(13), E(14), F(15)$. Weights are powers of $16^i$. Each Hex digit maps to a 4-bit binary group.

2.8 Binary Codes

2.8.1 BCD Code (Binary-Coded Decimal)

In BCD (specifically 8421 BCD), each decimal digit ($0-9$) is individually encoded into 4 binary bits. Combinations $1010$ to $1111$ ($10$ to $15$) are invalid/unassigned in BCD.

Example: $(23)_{10} \implies \mathbf{0010 \ 0011}_{\text{BCD}}$.

2.8.2 Excess-3 Code

Unweighted code formed by adding $3$ (0011) to the BCD code of each decimal digit. Property: It is a Self-Complementing Code (1's complement of Excess-3 code gives 9's complement of decimal number).

Example: Decimal $2 \implies 0010 + 0011 = \mathbf{0101}_{\text{XS-3}}$.

2.8.3 Gray Code

Gray code is a non-weighted unit-distance code: consecutive decimal numbers differ by exactly ONE bit. Used extensively in rotary optical shaft encoders to prevent transition errors.

1. Binary to Gray Code Formula:

For $n$-bit binary $b_{n-1}\dots b_0$ to Gray code $g_{n-1}\dots g_0$:

$$g_{n-1} = b_{n-1}$$ $$g_i = b_i \oplus b_{i+1} \quad (\text{Modulo-2 XOR addition: } 0\oplus0=0, 0\oplus1=1, 1\oplus0=1, 1\oplus1=0)$$
Example: Convert Binary 1010 (Decimal 10) to Gray Code
  • $g_3 = b_3 = \mathbf{1}$
  • $g_2 = b_2 \oplus b_3 = 0 \oplus 1 = \mathbf{1}$
  • $g_1 = b_1 \oplus b_2 = 1 \oplus 0 = \mathbf{1}$
  • $g_0 = b_0 \oplus b_1 = 0 \oplus 1 = \mathbf{1}$
  • Gray Code Result $= \mathbf{1111}_{\text{Gray}}$
2. Gray Code to Binary Formula:
$$b_{n-1} = g_{n-1}$$ $$b_i = g_i \oplus b_{i+1}$$
Example: Convert Gray Code 1001 (Decimal 14) to Binary
  • $b_3 = g_3 = \mathbf{1}$
  • $b_2 = g_2 \oplus b_3 = 0 \oplus 1 = \mathbf{1}$
  • $b_1 = g_1 \oplus b_2 = 0 \oplus 1 = \mathbf{1}$
  • $b_0 = g_0 \oplus b_1 = 1 \oplus 1 = \mathbf{0}$
  • Binary Result $= \mathbf{1110}_2 = 14_{10}$

2.8.4 Error-Detection Codes

1. Parity Bit:

An extra bit $P$ attached to data message to ensure total number of $1$s is either Even (Even Parity) or Odd (Odd Parity). Detects single-bit errors.

2. Cyclic Redundancy Check (CRC):

A powerful error-detecting technique using polynomial Modulo-2 Arithmetic (XOR without carries).

CRC কিভাবে কাজ করে? (Step-by-Step Mechanism):
১. আমাদের $k$-বিটের মেসেজ $M$ এবং একটি $(n+1)$-বিটের ডিভিজর প্যাটার্ন $P$ দেওয়া থাকবে।
২. FCS ($F$) তৈরি করতে মেসেজ $M$ এর ডানে $n$-টি শূন্য ($0$) বসানো হয় ($2^n M$)।
৩. $2^n M$ কে $P$ দিয়ে Modulo-2 ভাগ (Division) করা হয়। যে ভাগশেষ (Remainder $R$) থাকে, সেটাই হলো FCS।
৪. পাঠানো মেসেজ $T = 2^n M + R$। রিসিভার $T$ কে $P$ দিয়ে ভাগ করবে। ভাগশেষ $0$ হলে ডাটা নির্ভুল!

2.8.5 ASCII Character Code

ASCII (American Standard Code for Information Interchange) is a 7-bit alphanumeric code representing 128 ($2^7$) characters: 94 printable graphic characters (letters A-Z, a-z, digits 0-9, symbols) and 34 non-printable control characters.

Example: Letter 'A' in ASCII is represented as column $100_2$ and row $0001_2} \implies \mathbf{1000001_2} = 65_{10}$.
