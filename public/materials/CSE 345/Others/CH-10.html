10.1 Introduction to Sequential Logic Design

Part A: সহজ বাংলায় বিস্তারিত ব্যাখ্যা

১. Sequential Circuit কী?
কোনো ডিজিটাল সার্কিটে যদি অন্তত একটি Flip-Flop (মেমোরি উপাদান) থাকে, তবে তাকে Sequential Circuit বলে। এর সাথে AND, OR, NOT ইত্যাদি Combinational Gate থাকতেও পারে, আবার নাও থাকতে পারে। এই সার্কিটের আউটপুট কেবল বর্তমান ইনপুটের ওপর নির্ভর করে না—বরং সার্কিটের ভেতরে আগে থেকে কী মান জমা আছে (Present State), তার ওপরও নির্ভর করে।

২. Synchronous বনাম Asynchronous Sequential Circuit (পার্থক্য কী এবং কেন Synchronous ব্যবহার করি?):
• Asynchronous Sequential Circuit: এখানে কোনো ঘড়ি বা Clock (CK) থাকে না। ইনপুট যেকোনো মুহূর্তে বদলালে সার্কিটের অবস্থা সাথে সাথে বদলে যায়। এর বড় সমস্যা হলো—যদি দুটি ইনপুট প্রায় একই সময়ে বদলায়, তবে সার্কিটটি Unstable (অস্থির) হয়ে ভুল আউটপুট দিতে পারে।
• Synchronous (Clocked) Sequential Circuit: এখানে একটি মাস্টার Clock Pulse (CK) থাকে। ইনপুট যাই বদলাক না কেন, ঘড়ির কাঁটা বা Clock-এর নির্দিষ্ট পালস না আসা পর্যন্ত ফ্লিপ-ফ্লপের অবস্থা বদলায় না। এতে কোনো Instability (অস্থিরতা) থাকে না। তাই পুরো অধ্যায় ১০-এ আমরা শুধুমাত্র Clocked Synchronous Sequential Circuit নিয়ে কাজ করব।

৩. চারটি মূল উপাদান: প্রতিটি ক্লকড সিকোয়েনশিয়াল সার্কিটে চারটি বিষয় থাকে:
(১) External Inputs (x): বাইরে থেকে দেওয়া ইনপুট।
(২) Present State (Qn): ক্লক পালস আসার ঠিক আগে ফ্লিপ-ফ্লপে জমা থাকা মান।
(৩) Next State (Qn+1): ক্লক পালস আসার পর ফ্লিপ-ফ্লপে যে নতুন মান জমা হবে।
(৪) External Outputs (z): সার্কিট থেকে বাইরে বের হওয়া চূড়ান্ত আউটপুট।

Part B: Easy English — Exam Preparation (5 Marks)

Sequential Circuit: A digital logic circuit containing memory elements (flip-flops) along with combinational logic gates is called a sequential circuit. Its external outputs and next internal state are functions of both the external inputs and the present state of the flip-flops.

Basis Synchronous (Clocked) Sequential Circuit Asynchronous Sequential Circuit
Timing Control Behavior is defined only at discrete instants synchronized by a Clock (CK) pulse. Behavior depends on the order in which inputs change; affected at any instant without a clock.
Stability Highly stable; immune to race/instability issues. May become unstable, making design difficult.
Popularity Most widely used in modern digital systems. Less commonly used due to timing hazards.

Zero-to-Hero: How States Become Next States & How to Fill Transition Tables

Answering all 10 fundamental questions slowly, with progressive examples from 1 Flip-Flop to 2 Flip-Flops

Part A: একদম শূন্য থেকে ১০টি মৌলিক প্রশ্নের সহজ উত্তর

১. State (অবস্থা) কী?
সার্কিটের সবগুলো ফ্লিপ-ফ্লপের আউটপুটে এই মুহূর্তে যে বাইনারি সংখ্যা জমা আছে, তাকেই State বলে। যেমন: ২টি ফ্লিপ-ফ্লপ Q1 এবং Q2-তে যদি 0 এবং 1 জমা থাকে, তবে সার্কিটটি 01 স্টেটে আছে।

২. Present State বা Q(n) কী?
Clock pulse আসার ঠিক আগের মুহূর্তে ফ্লিপ-ফ্লপের ভেতরে যে মান জমা আছে। সময় t = n বোঝাতে একে Q(n) বা Qn লেখা হয়।

৩. Next State বা Q(n+1) কী?
একটি Clock pulse আসার ঠিক পরের মুহূর্তে (সময় t = n+1) ফ্লিপ-ফ্লপের আউটপুট আপডেট হয়ে যে নতুন মান তৈরি হয়, তাকে Q(n+1) বা Qn+1 বলে।

৪. External Input Combinations কেন লাগে?
ফ্লিপ-ফ্লপের পরবর্তী অবস্থা কেবল বর্তমান অবস্থার ওপর নির্ভর করে না, বাইরে থেকে তুমি কী সিগন্যাল (যেমন x = 0 নাকি x = 1) দিচ্ছ তার ওপরও নির্ভর করে। তাই সব সম্ভাব্য ইনপুট কম্বিনেশন টেবিলে রাখতে হয়।

৫. Clock Pulse কীভাবে State বদলায়?
ক্লক আসার আগে গেটগুলো হিসাব করে রাখে পরবর্তী মান কী হবে, কিন্তু আউটপুট বদলায় না। যেই মুহূর্তে Clock-এর ট্রিগার এজ (Edge) আসে, সাথে সাথে Q(n) মুছে গিয়ে Q(n+1)-এর মান ফ্লিপ-ফ্লপে লোড হয়ে যায়।

৬. Next State ও Output কীভাবে হিসাব করব?
খুবই সহজ! প্রথমে Next-State Equation (যেমন Qn+1 = x ⊕ Qn)-এ বর্তমান Qn এবং ইনপুট x-এর মান বসিয়ে Qn+1 বের করবে। তারপর Output Equation (যেমন z = x·Qn)-এ একই মান বসিয়ে z বের করবে।

With 2 flip-flops, there are 22 = 4 Present States: 00, 01, 10, 11. Suppose Q1(n+1) = x + Q2(n) and Q2(n+1) = Q1(n), with output z = Q1(n)·Q2(n). Let's calculate Row Q1Q2 = 01 for x = 0:

Here Q1(n) = 0, Q2(n) = 1, and x = 0:
1) Q1(n+1) = x + Q2(n) = 0 + 1 = 1
2) Q2(n+1) = Q1(n) = 0  ⇒  So Combined Next State Q1(n+1)Q2(n+1) = 10!

Transition Table vs. State Table (Exam Comparison)

Transition Table State Table
Uses binary values (e.g., 00, 01, 10, 11) for states. Uses alphabetic symbols (e.g., A, B, C, D) for states.
Shows exact flip-flop bit transitions (Q1nQ2n → Q1n+1Q2n+1). Compact, abstract representation independent of flip-flop bit coding.
Used directly for circuit analysis & deriving K-maps. Used for state reduction and high-level behavioral design.

How a Transition Table Becomes a Transition Diagram:

  1. Draw Circles (Nodes): Draw one circle for each state (e.g., 00, 01, 10, 11).
  2. Draw Arrows (Directed Edges): Look at row 00. If input x = 0 sends the circuit to Next State 10 with output z = 1, draw an arrow starting at circle 00 and pointing to circle 10.
  3. Label the Arrow (Input / Output): Write 0 / 1 on that arrow (meaning: when input is 0, output is 1).
  4. Self-Loops: If Next State equals Present State (e.g., 11 → 11), draw a curved arrow looping back into the same circle.

Part A: সহজ বাংলায় Analysis বা সার্কিট বিশ্লেষণের ৪টি ধাপ

Analysis (বিশ্লেষণ) মানে হলো তোমাকে একটি আঁকা সার্কিট ডায়াগ্রাম দেওয়া থাকবে, আর তোমাকে বের করতে হবে সার্কিটটি কী কাজ করে (অর্থাৎ Transition Table ও Transition Diagram আঁকতে হবে)। এটি ঠিক Design-এর উল্টো প্রক্রিয়া!

  2. ধাপ ২: Flip-Flop-এর Characteristic Equation-এ (যেমন JK-এর ক্ষেত্রে Qn+1 = J·Q'n + K'·Qn) ধাপ ১-এর মান বসিয়ে Boolean Algebra দিয়ে সরল করো।

1. Excitation & Output Equations from Gates:
J1n = Q2'n
K1n = x·Q1'n + x'·Q2n
J2n = x·Q1'n
K2n = x'·Q1'n + x'·Q1n = x'(Q1'n + Q1n) = x'
z1 = x·Q1n + x'·Q1'n
z2 = x'·Q1'n + x'·Q1n = x'
2. Next-State Equation Derivation (JK Characteristic: Qn+1 = JQ' + K'Q):
Q1n+1 = J1nQ1'n + K1'nQ1n
  = Q2'nQ1'n + (xQ1'n + x'Q2n)' · Q1n
  = Q1'nQ2'n + (x' + Q1n)(x + Q2'n)Q1n [De Morgan's Law]
  = Q1'nQ2'n + (x'Q2'n + xQ1n + Q1nQ2'n)Q1n
  = Q1'nQ2'n + x'Q1nQ2'n + xQ1n + Q1nQ2'n
  = Q1'nQ2'n + Q1nQ2'n(x' + 1) + xQ1n [x' + 1 = 1]
  = Q2'n(Q1'n + Q1n) + xQ1n [Q1' + Q1 = 1]
  = Q2'n + xQ1n
Q2n+1 = J2nQ2'n + K2'nQ2n = xQ1'nQ2'n + xQ2n

10.4.1 State Reduction (Every Intermediate Step from Table 10.4 to Table 10.8)

Part A: সহজ বাংলায় State Reduction-এর নিয়ম

১. State Reduction কী এবং কেন করি?
অনেক সময় ডিজাইন করার সময় সার্কিটে প্রয়োজনের চেয়ে বেশি State তৈরি হয়ে যায়। দুটি স্টেট যদি হুবহু একই কাজ করে, তবে একটিকে বাদ দিলে সার্কিটের বাইরের কাজের কোনো পরিবর্তন হয় না, কিন্তু Flip-Flop এবং Gate-এর সংখ্যা ও খরচ কমে যায়। একে State Reduction বলে।

২. দুটি স্টেট কখন Equivalent (সমতুল্য) হয়? (২টি শর্তই পূরণ হতে হবে):

• শর্ত ১: প্রতিটি ইনপুটের (x=0 এবং x=1) জন্য দুজনের Output একদম সমান হতে হবে।

Part B: Exam-Ready Definition (5 Marks):
State Reduction is the systematic process of reducing the number of states in a state table without altering the external input-output behavior of the sequential circuit. Theorem of State Equivalence: Two states are said to be equivalent if, for each possible input combination, they produce the exact same output and transition either to the same next state or to equivalent next states. When two states are equivalent, one is eliminated and all references to it are replaced by its equivalent partner.

10.5 Complete 15-Step Sequential Circuit Design Blueprint, Excitation & K-Map Rules

Exact 15-Step Design Sequence (Why & How)

  1. Understand Word Problem: Identify what sequence or behavior must be detected/counted.
  2. Identify Inputs & Outputs: Name external inputs (e.g., x) and outputs (e.g., z).
  3. Draw State Diagram: Create circles for states and directed arrows labeled input/output.
  4. Prepare State Table: Convert the state diagram into a tabular form.
  5. Perform State Reduction: Eliminate equivalent states (if outputs are not taken directly from FFs).
  6. Calculate Flip-Flop Count (m): Choose smallest m such that 2m ≥ Number of States.
  7. Assign Binary Values: Map each symbolic state (A, B...) to a unique m-bit binary code.
  8. Prepare Transition Table: Replace state letters with their binary codes.
  9. Choose Flip-Flop Type: Select D, T, JK, or SR flip-flops as specified.
  10. Prepare Excitation Table: Compare Present State Qn → Next State Qn+1 bit-by-bit using the FF's excitation rules.
  11. Transfer to K-Maps: Create one K-map per FF input (e.g., J1, K1, J2, K2) and one per output (z). Include unused states as X.
  12. Simplify FF Input Equations: Group 1s (and helpful Xs) in sizes of 8, 4, 2, or 1 using Gray Code (00, 01, 11, 10).
  13. Derive Output Equation: Simplify output z via K-map.
  14. Draw Logic Diagram: Draw flip-flops, connect CK, and wire gates to FF inputs & output.
  15. Verify Design: Check unused states to confirm self-starting behavior.

K-Map Placement & Grouping Rules (Steps 11–12):

• Gray Code Order: Always label 2-variable axes as 00, 01, 11, 10 (never 10 before 11!).

• Minterm Index Formula: For variables (Q1, Q2, x), minterm index = 4·Q1 + 2·Q2 + 1·x. Example: Row Q1Q2 = 10 and x = 1 is binary 101 = minterm 5.

• Grouping Sizes: Form the largest possible rectangular/wrap-around groups of 8 (Octet), 4 (Quad), 2 (Pair), or 1 (Single). Use Xs only to enlarge a group containing at least one 1.

Initial States, Master Reset (RST), Unused States & Self-Starting Circuits

Part A: সহজ বাংলায় ব্যাখ্যা

১. Initial State ও Master Reset (RST): সার্কিটে প্রথম পাওয়ার অন করলে ফ্লিপ-ফ্লপগুলো কোন অবস্থায় থাকবে তা আগে থেকে জানা থাকে না (হয়তো একটি Invalid বা Unused স্টেটে চালু হতে পারে!)। তাই ক্লক শুরু হওয়ার আগে সব ফ্লিপ-ফ্লপকে একটি নির্দিষ্ট শুরুর অবস্থায় আনতে Master Reset (RST) ইনপুট ব্যবহার করা হয়। এটি Asynchronous (ক্লকের তোয়াক্কা করে না)—ফ্লিপ-ফ্লপের Preset (Pr) এবং Clear (Cr) পিনের মাধ্যমে কাজ করে। যেমন Figure 10.14-এ RST = 0 দিলে সার্কিট সরাসরি বৈধ শুরুর স্টেট 001-এ চলে আসে (FF1 ও FF2 ক্লিয়ার হয়ে 0 হয়, এবং FF3 প্রিসেট হয়ে 1 হয়)।

২. Self-Starting ও Self-Correcting Circuit কী?
যদি কোনো দুর্ঘটনা বা নয়েজের কারণে সার্কিট একটি Unused (Invalid) State-এ ঢুকে পড়ে (যেমন Example 2-এ 000, 110, 111), এবং ১ বা ২টি ক্লক পালসের মধ্যেই নিজে থেকেই একটি Valid State-এ ফিরে এসে স্বাভাবিকভাবে চলতে শুরু করে, তবে সেই সার্কিটকে Self-Starting এবং Self-Correcting Circuit বলে।

Part B: Exam-Ready English Answer (5 Marks)

Master Reset (Asynchronous Initialization): When power is initially turned on, flip-flops settle into unpredictable states. A Master Reset (RST) signal is applied asynchronously to the Preset (Pr) and Clear (Cr) pins before clocked operation begins to force the circuit into a known valid initial state (e.g., setting Q1Q2Q3 = 001 when RST = 0 in Figure 10.14, and enabling normal operation when RST = 1).

Self-Starting & Self-Correcting Circuit: A sequential circuit is said to be self-starting (and self-correcting) if, upon entering any unused/invalid state (such as 000, 110, 111 in Table 10.19), it automatically transitions into one of the valid operational states within a finite number of clock pulses without getting trapped in an invalid loop.
