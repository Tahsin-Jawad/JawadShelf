1. Correlated Subqueries & Logic

Row-by-row outer query evaluation based on inner subquery execution

Concept 1.1

What is a Correlated Subquery?

Row-by-Row Execution

সাধারণ Subquery একবার এক্সিকিউট হয়ে রেজাল্ট দিয়ে দেয়। কিন্তু Correlated Subquery-তে ইনার সাবকুয়েরিটি আউটার কুয়েরির প্রতিটি সারির (Row) জন্য বারবার এক্সিকিউট হয়।

Query: Find Employees Earning MORE than their Department's Average Salary 

SELECT e1.Name, e1.salary, e1.Dept_code
FROM employee E1
WHERE e1.salary > (
    SELECT AVG(e2.salary)
    FROM employee E2
    WHERE e1.Dept_code = e2.Dept_code -- Correlated Link!
);
How Engine Executes This Row-by-Row:
  1. আউটার কুয়েরি E1 প্রথম কর্মীকে ধরে (যেমন: Robin, Dept: HR, Salary: 30,000)।
  2. ইনার কুয়েরি E2 কেবল Dept_code = 'HR' এর কর্মীদের গড় বেতন হিসাব করে (যেমন: 25,000)।
  3. তুলনা করে: 30,000 > 25,000 (True) $\rightarrow$ Robin আউটপুটে জায়গা পায়!
Concept 1.2

General Formulas for N-th Highest & N-th Lowest Salary

Subquery dynamic counting rule without using hardcoded LIMIT offset

N-th Highest Salary Formula Formula: N - 1 
SELECT e1.salary
FROM employee E1
WHERE N - 1 = (
    SELECT COUNT(DISTINCT e2.salary)
    FROM employee E2
    WHERE e2.salary > e1.salary
);
📌 ২য় সর্বোচ্চ Salary (2nd Highest):

$N = 2$, তাই $N - 1 = 1$। যে বেতনের চেয়ে বড় ঠিক ১টি ইউনিক বেতন থাকবে, সেটিই ২য় সর্বোচ্চ বেতন!

N-th Lowest Salary Formula Formula: N - 1 
SELECT e1.salary
FROM employee E1
WHERE N - 1 = (
    SELECT COUNT(DISTINCT e2.salary)
    FROM employee E2
    WHERE e2.salary < e1.salary
);
📌 ৩য় সর্বনিম্ন Salary (3rd Lowest):

$N = 3$, তাই $N - 1 = 2$। যে বেতনের চেয়ে ছোট ঠিক ২টি ইউনিক বেতন থাকবে, সেটিই ৩য় সর্বনিম্ন বেতন!

2. Comprehensive SQL Joins Matrix

Combining relational tables: Inner, Left, Right, Natural & Full Outer Joins

1. INNER JOIN (Equi Join) Matches Only

উভয় টেবিলে ম্যাচ করা সারিসমূহ প্রদর্শন করে।

SELECT * FROM Department D
INNER JOIN employee E ON E.dept_code = D.dept_code;
2. NATURAL JOIN Auto Match Column

একই কলাম নেমের ওপর ভিত্তি করে স্বয়ংক্রিয় Join ঘটায় (ON লাগে না)।

SELECT * FROM Department D
NATURAL JOIN employee E;
3. LEFT OUTER JOIN All Left + Matched Right

বাম টেবিলের সব ডাটা থাকবে, ডান টেবিলে অমিল থাকলে NULL দেখাবে।

SELECT * FROM Department D
LEFT JOIN employee E ON E.dept_code = D.dept_code;
4. RIGHT OUTER JOIN All Right + Matched Left

ডান টেবিলের সব ডাটা থাকবে, বাম টেবিলে অমিল থাকলে NULL দেখাবে।

SELECT * FROM Department D
RIGHT JOIN employee E ON E.dept_code = D.dept_code;
5. FULL OUTER JOIN (Simulated in MySQL using UNION) LEFT JOIN ∪ RIGHT JOIN

MySQL-এ সরাসরি `FULL JOIN` নেই। তাই `LEFT JOIN` এবং `RIGHT JOIN`-কে `UNION` করতে হয়।

SELECT * FROM Department D LEFT JOIN employee E ON E.dept_code = D.dept_code
UNION
SELECT * FROM Department D RIGHT JOIN employee E ON E.dept_code = D.dept_code;

3. Self Join & Manager-Employee Hierarchies

Joining a table to itself using dual table aliases

3.1 Schema & Setup for Manager Hierarchy 

-- Employees Table with Manager ID
CREATE TABLE employees (
    employee_id INT PRIMARY KEY,
    employee_name VARCHAR(50),
    job_title VARCHAR(50),
    salary INT,
    manager_id INT
);

INSERT INTO employees VALUES
(1, 'Alice', 'CEO', 150000, NULL),
(2, 'Bob', 'VP of Engineering', 110000, 1),
(3, 'Charlie', 'VP of Marketing', 100000, 1),
(4, 'David', 'Software Engineer', 180000, 2),
(5, 'Eve', 'DevOps Specialist', 85000, 2);

Query: Employees Earning MORE than their Direct Manager

Self Join Logic 
SELECT 
    E.employee_name AS Employee_Name,
    E.salary AS Employee_Salary, 
    M.employee_name AS Manager_Name, 
    M.salary AS Manager_Salary
FROM employees E 
INNER JOIN employees M ON E.manager_id = M.employee_id
WHERE E.salary > M.salary;
Employee_Name Employee_Salary Manager_Name Manager_Salary
David 180,000 Bob 110,000

💡 ব্যাখ্যা: ডেভিড ১৮০,০০০ টাকা আয় করে যা তার ম্যানেজার বব (১১০,০০০ টাকা)-এর চেয়ে বেশি!

4. Set Operations, Semi-Joins & Anti-Semi Joins

UNION, INTERSECT, EXCEPT and Subquery Membership checks

UNION vs UNION ALL

// UNION (Removes duplicates)
SELECT customerid FROM customers
UNION
SELECT customerid FROM orders;

// UNION ALL (Keeps duplicates, faster)
SELECT customerid FROM customers
UNION ALL
SELECT customerid FROM orders;

INTERSECT & EXCEPT

// INTERSECT (Both tables)
SELECT customerid FROM customers
INTERSECT
SELECT customerid FROM orders;

// EXCEPT / MINUS (In 1st, NOT in 2nd)
SELECT customerid FROM customers
EXCEPT
SELECT customerid FROM orders;

Semi Join vs Anti-Semi Join
// Semi Join (IN / EXISTS)

SELECT * FROM customers
WHERE customerid IN (
  SELECT customerid FROM orders
);

যেসব কাস্টমার অন্তত ১টি অর্ডার করেছে
// Anti Semi Join (NOT IN / NOT EXISTS)

SELECT customername FROM customers
WHERE customerid NOT IN (
  SELECT customerid FROM orders
);

যেসব কাস্টমার কখনোই কোনো অর্ডার করেনি

5. Pagination, LIMIT & Execution Pipeline

Standard syntax clause sequence vs internal logical database execution order

1. Written SQL Syntax Clause Sequence (যেভাবে কোড লিখি):
1. SELECT 2. FROM 3. WHERE 4. GROUP BY 5. HAVING 6. ORDER BY 7. LIMIT
2. Internal Logical Execution Order (ডাটাবেজ ইঞ্জিন যেভাবে প্রসেস করে):
1. FROM / JOIN 2. WHERE 3. GROUP BY 4. HAVING 5. SELECT 6. ORDER BY 7. LIMIT
// Top 1 Record

SELECT * FROM employees LIMIT 1;

// Offset Pagination (Skip 3, get 1)

SELECT * FROM employees LIMIT 3, 1;

// Highest Salary using Order & Limit

SELECT * FROM employees ORDER BY salary DESC LIMIT 1;

6. Lab 4 Viva Questions & Answers

Interactive flashcards for Lab exam oral tests

Q1 What is the difference between a normal subquery and a correlated subquery?

স্বাভাবিক Subquery কেবল একবার এক্সিকিউট হয়ে আউটার কুয়েরিতে ডাটা পাস করে। কিন্তু Correlated Subquery-তে আউটার কুয়েরির প্রতিটি Row এর জন্য ইনার সাবকুয়েরিটি বারবার এক্সিকিউট হয়।

Q2 Why doesn't MySQL directly support FULL OUTER JOIN? How do we write it?

MySQL-এর ইন্টারনাল ইঞ্জিনে `FULL OUTER JOIN` কিওয়ার্ডের ডিরেক্ট সাপোর্ট নেই। তাই আমরা `LEFT JOIN` এবং `RIGHT JOIN` এর ফলাফলের সাথে `UNION` ব্যবহার করে FULL JOIN এর আউটপুট তৈরি করি।

Q3 What is a Self Join and when is it required?

যখন একটি টেবিল নিজের কলামগুলোর সাথে তুলনা করার জন্য নিজের সাথে নিজেই Join করে, তাকে Self Join বলে। উদাহরণস্বরূপ: Employee-Manager Hierarchy বের করতে, একই টেবিলে কাস্টমারদের মধ্যে তুলনা করতে ইত্যাদি।

Q4 What is the difference between UNION and UNION ALL?

`UNION` দুইটি রেজাল্ট সেটের মধ্যে ডুপ্লিকেট সারিগুলো বাদ দিয়ে কেবল ইউনিক সারিগুলো দেখায়। আর `UNION ALL` কোনো ডুপ্লিকেট বাদ দেয় না এবং সর্টিং ছাড়া দ্রুত ডাটা কম্বাইন করে।
