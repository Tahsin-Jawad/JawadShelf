Lab 1: Data Definition (DDL) & Manipulation (DML)

ডাটাবেজ এবং টেবিল তৈরি, স্ট্রাকচার মডিফিকেশন এবং মৌলিক CRUD অপারেশনস

⚠️ Correction in Raw Notes:
  • আপনার নোটে হেডিং ছিল DLD। সঠিক টার্মটি হলো DDL (Data Definition Language)।
  • ALTER TABLE CHANGE কমান্ডে নতুন কলামের ডাটা টাইপ varchar(20) লেখা বাকি ছিল, যা পরবর্তীতে ভুল সিনট্যাক্স তৈরি করত। নিচে তা সংশোধন করা হয়েছে।

1.1 Data Definition Language (DDL)

CREATE | ALTER | DROP | TRUNCATE

Database Creation and Removal 

CREATE DATABASE University;

DROP DATABASE University;

👉 CREATE DATABASE: একটি নতুন ডাটাবেজ স্টোরেজ তৈরি করে।

👉 DROP DATABASE: পুরো ডাটাবেজ এবং তার সকল টেবিল ডাটা সহ চিরতরে মুছে ফেলে।

Table Creation (student) 

CREATE TABLE student( 
    student_id INT,
    name VARCHAR(20),
    CGPA DECIMAL(3,2)
);
💡 DECIMAL(3,2) অর্থ: সর্বমোট ৩টি ডিজিট থাকতে পারবে, যার মধ্যে দশমিকের পর অবশ্যই ২টি ডিজিট থাকবে (যেমন: 3.75)।

Altering Table Structure (ADD, MODIFY, DROP, CHANGE) 

-- ১. টেবিলে নতুন কলাম যুক্ত করা
ALTER TABLE student ADD AGE INT;

-- ২. কলামের ডাটা টাইপ পরিবর্তন (INT থেকে VARCHAR)
ALTER TABLE student MODIFY student_id VARCHAR(20);

-- ৩. কলামের নাম ও ডাটা টাইপ একসাথে পরিবর্তন করা (⚠️ Corrected syntax)
ALTER TABLE student CHANGE name STUDENT_NAME VARCHAR(20);

-- ৪. কলাম মুছে ফেলা
ALTER TABLE student DROP COLUMN AGE;

Rename, Truncate & Drop Table 

-- টেবিল রিনেম করা
RENAME TABLE student TO STUDENT_CSE;

-- টেবিলের সব ডাটা খালি করা (কাঠামো/স্ট্রাকচার থেকে যাবে)
TRUNCATE TABLE STUDENT_CSE;

-- টেবিল ডাটা ও স্ট্রাকচার দুটোই মুছে ফেলা
DROP TABLE STUDENT_CSE;

1.2 Data Manipulation Language (DML) & Filtering

INSERT | SELECT | UPDATE | DELETE

1. Inserting Rows Into STUDENT_CSE

-- সিঙ্গল রো ইনসার্ট
INSERT INTO STUDENT_CSE (student_id, name, CGPA) VALUES (100, 'ALICE', 3.00);

2. SELECT, WHERE, BETWEEN, IN & DISTINCT

-- ১. specific id filtering
SELECT * FROM STUDENT_CSE WHERE student_id = 101;

-- ২. Multiple conditions (OR)
SELECT * FROM STUDENT_CSE WHERE student_id = 101 OR student_id = 102;

-- ৩. NULL Value খোঁজা (IS NULL)
SELECT * FROM STUDENT_CSE WHERE CGPA IS NULL;

-- ৪. Range Filtering (BETWEEN inclusive)
SELECT * FROM STUDENT_CSE WHERE student_id BETWEEN 100 AND 103;

-- ৫. List Matching (IN operator)
SELECT * FROM STUDENT_CSE WHERE student_id IN (100, 102);

-- ৬. Unique values প্রদর্শন
SELECT DISTINCT name FROM STUDENT_CSE;

3. UPDATE & DELETE Operations

-- ১. ডাটা আপডেট করা (ID 104 এর নাম AKIF -> ASHIK)
UPDATE STUDENT_CSE 
SET name = 'ASHIK' 
WHERE student_id = 104;

-- ২. Specific Row মুছে ফেলা
DELETE FROM STUDENT_CSE WHERE CGPA IS NULL;

-- ৩. পুরো টেবিলের সব সারি মুছে ফেলা (WHERE 1 অথবা WHERE TRUE)
DELETE FROM STUDENT_CSE WHERE 1;
DELETE FROM table WHERE 1; কমান্ডটি টেবিলের সকল ডাটা মুছে ফেলে কারণ শর্ত 1 (True) সবসময় প্রযোজ্য!

Lab 2: Aggregate Functions & Pattern Matching

COUNT, SUM, GROUP BY এবং LIKE Operator ওয়াইল্ডকার্ড ট্রিকস

2.1 Aggregate Functions & GROUP BY 

-- ১. মোট নন-নাল বেতনের সংখ্যা গণনা
SELECT COUNT(salary) FROM employee;

-- ২. ইউনিক বেতনের সংখ্যা বের করা
SELECT COUNT(DISTINCT salary) FROM employee;

-- ৩. মোট বেতনের সাম বা যোগফল
SELECT SUM(salary) FROM employee;

-- ৪. নির্দিষ্ট ডিপার্টমেন্টের বেতনের যোগফল (WHERE filter)
SELECT dept, SUM(salary) FROM employee WHERE dept = 'HR';

-- ৫. বিভাগ অনুযায়ী কর্মচারীর মোট সংখ্যা (GROUP BY)
SELECT dept, COUNT(*) FROM employee GROUP BY dept;

-- ৬. বিভাগ অনুযায়ী মোট বেতন
SELECT dept, SUM(salary) FROM employee GROUP BY dept;

2.2 Pattern Matching with Wildcards (% and _)

% = ০, ১ বা একাধিক ক্যারেক্টার | _ = ঠিক ১টি নির্দিষ্ট ক্যারেক্টার

// Ending with 'i'

SELECT E_name FROM employee WHERE E_name LIKE '%i';

// Starting with 'M'

SELECT dept FROM employee WHERE dept LIKE 'M%';

// 2nd letter is 'o'

SELECT E_name FROM employee WHERE E_name LIKE '_o%';

// Doesn't contain 'a'

SELECT dept FROM employee WHERE dept NOT LIKE '%a%';

// Exactly 5 letters starting with 'R'

SELECT E_name FROM employee WHERE E_name LIKE 'R____';

// Salary NOT NULL & contains 'n'

SELECT E_name FROM employee WHERE salary IS NOT NULL AND E_name LIKE '%n%';

Advanced Pattern Trick: Exactly ONE 'A' in Name

// Approach 1: Wildcard combination

SELECT E_name FROM employee WHERE E_name LIKE '%A%' AND E_name NOT LIKE '%A%A%';

// Approach 2: String Length Trick (Fixed Syntax from raw notes)

SELECT E_name FROM employee WHERE LENGTH(E_name) - LENGTH(REPLACE(LOWER(E_name), 'a', '')) = 1;

💡 ব্যাখ্যা: মূল নামের লেন্থ থেকে 'a' মুছে ফেলার পর লেন্থ বিয়োগ করলে যদি ১ থাকে, তবে নামটিতে ঠিক ১টিই 'a' ছিল!

3.1 Creating Parent and Child Tables with Constraints 

-- ১. Department টেবিল (Parent Table)
CREATE TABLE Department (
    dept_code VARCHAR(20),
    dept_name VARCHAR(50), 
    PRIMARY KEY (dept_code)
);

-- ২. Employee টেবিল (Child Table with FK, AUTO_INCREMENT & CHECK)
CREATE TABLE employee (
    emp_id INT AUTO_INCREMENT,
    name VARCHAR(30),
    salary INT CHECK (salary BETWEEN 10000 AND 80000),
    dept_code VARCHAR(20),
    PRIMARY KEY (emp_id),
    FOREIGN KEY (dept_code) REFERENCES Department (dept_code)
) AUTO_INCREMENT = 101;

3.2 Practice Queries & Aliases

Practice Q1: Display Employee info with Department Name
SELECT E.*, D.dept_name FROM employee E, Department D WHERE E.dept_code = D.dept_code;
Practice Q2: Display name and salary of 'Human Resources' employees
SELECT E.name, E.salary FROM employee E, Department D WHERE E.dept_code = D.dept_code AND D.dept_name = 'Human Resources';
Practice Q4 & Q5: Finding 2nd Highest Salary & Employee Details
// Q4: Find only 2nd Highest Salary value (Output: 45000)
SELECT MAX(salary) FROM employee WHERE salary < (SELECT MAX(salary) FROM employee);
// Q5: Find Employee Name & Salary getting 2nd Highest Salary
SELECT name, salary FROM employee WHERE salary = ( SELECT MAX(salary) FROM employee WHERE salary < (SELECT MAX(salary) FROM employee) );
⚠️ Correction on your Raw Note's Comment:
আপনার নোটে লেখা ছিল: "if there will specific value then we will use 'in', otherwise '='".
সঠিক নিয়ম: Subquery যদি একমাত্র ১টি Single Value (1 row, 1 col) দেয়, তবে = ব্যবহার করা সঠিক। কিন্তু Subquery থেকে যদি একাধিক Rows আসার সম্ভাবনা থাকে, তখন IN ব্যবহার করতে হয়।

3.3 Query Evolution: Step-by-Step Building to Final Answer

যেসব ডিপার্টমেন্টের গড় বেতন, পুরো কোম্পানির গড় বেতনের চেয়ে বেশি তাদের বের করার পদ্ধতি

⭐ Lab Final Query
⚡ Mandatory SQL Execution Order (ইঞ্জিন যেভাবে সিরিয়াল মেনে চলে):
1. FROM 2. WHERE 3. GROUP BY 4. HAVING 5. SELECT 6. ORDER BY

Step 1: Department-wise Average Salary বের করা

SELECT dept_code, AVG(salary) FROM employee GROUP BY dept_code;

প্রথমে ডিপার্টমেন্ট অনুযায়ী ভাগ করে তাদের গড় বেতন বের করে নিলাম।

Step 2: HAVING ও Total Avg Subquery যুক্ত করা (Department Name ছাড়া)

SELECT dept_code, AVG(salary) FROM employee GROUP BY dept_code HAVING AVG(salary) > (SELECT AVG(salary) FROM employee);

এখানে HAVING ব্যবহার করেছি কারণ Aggregate Function (AVG) এর ওপর ফিল্টার বসাতে WHERE কাজ করে না।

🏆 Step 3 (Final Solution): Department Table Join করে Name নিয়ে আসা

SELECT E.dept_code, D.dept_name, AVG(E.salary) AS avg_salary
FROM employee E, Department D
WHERE E.dept_code = D.dept_code
GROUP BY E.dept_code, D.dept_name
HAVING AVG(E.salary) > (SELECT AVG(salary) FROM employee);
Expected Output Result:
dept_code dept_name avg_salary
ITInformation Tech45000.0000
MKTMarketing45000.0000

* কোম্পানির সামগ্রিক গড় বেতন ছিল 41000। তাই IT (45k) এবং MKT (45k) এই শর্তে পাস করেছে।

Alternative 3-Level Subquery Version (From your raw notes):
SELECT dept_name FROM Department WHERE dept_code IN ( SELECT dept_code FROM employee GROUP BY dept_code HAVING AVG(salary) > (SELECT AVG(salary) FROM employee) );

3.4 Foreign Key Constraints & ON UPDATE/DELETE CASCADE

যদি আমরা CASCADE ছাড়া সরাসরি Department টেবিলের dept_code পরিবর্তন করতে যাই:

UPDATE Department SET dept_code = 'CSE' WHERE dept_code = 'IT';
❌ Error: Cannot delete or update a parent row: a foreign key constraint fails!
কারণ employee টেবিলে 'IT' কোডটি Foreign Key হিসেবে যুক্ত আছে।

সমাধান: ON UPDATE CASCADE & ON DELETE CASCADE যুক্ত করা

CREATE TABLE employee (
    emp_id INT AUTO_INCREMENT,
    name VARCHAR(30),
    salary INT,
    dept_code VARCHAR(20),
    PRIMARY KEY (emp_id),
    FOREIGN KEY (dept_code) REFERENCES Department (dept_code)
        ON DELETE CASCADE
        ON UPDATE CASCADE
) AUTO_INCREMENT = 101;
ON UPDATE CASCADE: প্যারেন্ট টেবিলে ডিপার্টমেন্ট কোড চেঞ্জ হলে চাইল্ড টেবিলে সকল এমপ্লয়ির ডিপার্টমেন্ট কোড অটোমেটিক আপডেট হয়ে যাবে।
ON DELETE CASCADE: প্যারেন্ট টেবিল থেকে কোনো ডিপার্টমেন্ট মুছে দিলে ওই বিভাগের সকল এমপ্লয়ি তথ্য স্বয়ংক্রিয়ভাবে মুছে যাবে।

⚡ Quick Revision Summary

পরীক্ষা ও ভাইভার জন্য দ্রুত রিভিশন পয়েন্টসমূহ

DDL

Data Definition Language

CREATE, ALTER, DROP, TRUNCATE, RENAME. এগুলো ডাটাবেজের কাঠামো তৈরি ও পরিবর্তন করে। (Auto-commit)

DML

Data Manipulation Language

INSERT, SELECT, UPDATE, DELETE. এগুলো টেবিলের ভেতরের রো বা ডাটা ম্যানিপুলেট করে।

W vs H

WHERE vs HAVING

WHERE কাজ করে Individual rows এর ওপর (Group করার আগে)। HAVING কাজ করে Aggregated Groups এর ওপর।
